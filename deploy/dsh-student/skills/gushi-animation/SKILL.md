# 古诗情景动画（第 2 课）

学生做完这件作品，就能在浏览器里点开看：一首古诗的画面 + 一段旁白 + 一个播放入口。

## 要做到什么

1. 用中文问清楚：**哪一首诗**、想突出哪一句、画面想要什么色调（不要一次问一堆问题）。
2. 产出一个 **`index.html`**，满足：
   - 单文件，能直接双击打开就播放；不要依赖任何 CDN 或在线接口（学生环境禁止外网）。
   - 画面上要有：诗题、选中的那一句、至少三个场景（诗句 → 对应的画面）。
   - 有一个「播放 / 重播」按钮，点了之后场景依次出现（用 CSS 动画或 JS 定时器都行）。
   - 画面用 CSS 渐变、形状、emoji 或本地上传的图片拼出来；**不要**引用外部图片。
3. 每个场景旁边用一行小字写清楚「这一句诗为什么配这个画面」——这是课上的教学点。

## 硬性要求（做错会被打回）

- 只交 HTML/CSS/JS，不要引外网资源，不要用 `<script src="https://...">`。
- 页面不能报错：控制台里出现红色错误就算没做完。
- 作品语言是中文；文字不要溢出容器，手机宽度（390px）也要能看。
- 做完后**把 index.html 用 present 声明为交付物**，学生才能提交。

## 交付话术

做完不要只说「完成了」，要说清楚：做了哪一首诗、三个场景分别是什么、学生下一步能改哪里。
