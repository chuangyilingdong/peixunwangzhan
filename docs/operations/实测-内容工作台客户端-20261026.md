## 发现的问题

### P1 · 服务端转写可靠性不足（已修复并生产验证）

根因不是视频下载，而是把 23–63MB 的整段视频直接上传给 Whisper。只有最小的 23MB 素材成功，较大的素材分别出现 `fetch failed`、180 秒超时和上游 HTTP 524。

修复：

- 服务端先用 ffmpeg 抽取 16kHz 单声道、24kbps 音频；
- 按 5 分钟切片；
- 每片最多重试 3 次；
- 合并分片时间码、文本和时长；
- 错误文本先剥离 HTML，避免把整页 524 响应写给用户。

验证：

- 本地 660 秒音频切成 3 片，每片约 0.9MB；
- staging 用生产 ASR Key 处理此前失败的 40MB 视频：2 片、26.7 秒、209 段、1800 字；
- 生产发布后重试 613 秒视频：成功，367 段；
- 生产发布后重试 487 秒视频：成功，223 段。
