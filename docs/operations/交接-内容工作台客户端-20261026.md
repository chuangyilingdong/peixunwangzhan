### 登录与账号

- 直接调用 `POST https://aicyld.com/api/auth/login`；
- `clientType=org`，与网站使用同一账号体系；
- 支持二次验证码字段；
- 登录失败能显示平台原始错误；
- 会话通过 Electron `safeStorage` 加密保存，不保存密码；
- 退出登录会清理 `persist:junshi-content-workbench` 的 localStorage、cookies、IndexedDB、service workers 和 cache storage。

### 工作台窗口

- 独立 BrowserWindow；
- 使用持久化 partition：`persist:junshi-content-workbench`；
- 加载 `https://aicyld.com/junshi/index.html`；
- 登录态注入后自动 reload；
- 自动点击“内容工作台”导航，避免停留在专家团首页；
- 有桌面标识：`window.__JUNSHI_DESKTOP__ = { version }`；
- 外链交给系统浏览器；
- 服务端同域链接允许在客户端打开。

## 注意事项

1. 当前客户端 UI 加载的是生产网页，不是本地打包页面；断网无法使用工作台。
2. 深色主题依赖现有工作台 DOM，若网页结构调整，需要同步更新 `workbench-dark.css`。
3. 客户端当前没有托盘和自动更新。
4. 客户端没有本地抖音浏览器，因此还没有真正解决服务器 IP 被抖音风控的问题。
5. `E:\灵动ai客户端` 与本项目无关。
6. 当前客户端代码尚未 commit。
