## 二、每条做了什么

### ① 取消「素材」大类，导航就是大分组

`packages/shared/src/canvasWorkspace.jsx`：

- 导航改成**一个分组一项**（`group:<id 或下标>`），点哪个只看哪一组；
  面板只渲染 `activeGroup`，不再把一个长列表从头滚到尾。
- **本地素材单列一项**（学生从电脑拖进画布的那些）。原来它混在「素材」面板顶上，
  现在没有那一层了，混进某个分组里会更乱。
- 一组都没有时仍给一句明确的空态（别让学生看到白面板）。
- 画布面板上那个「✦ 生图 · 1k · …」的配置芯片点进来时，会打开**有生成框体的那一组**
  （以前指向已取消的「素材」面板）。

### ② 类型要能一眼分开

新增 `packages/shared/src/materialTypes.js` —— **唯一一份**「类型 → 图标 / 名字 / 色调」映射：

| 类型 | 名字 | 色调 |
|---|---|---|
| 生成框体 · IMAGE | 生图框体 | image（蓝） |
| 生成框体 · VIDEO | 生视频框体 | video（紫） |
| 生成框体 · MUSIC | 生音乐框体 | audio（粉） |
| 生成框体 · TEXT | 生文字框体 | prompt（柠檬绿） |
| IMAGE / VIDEO / AUDIO / PROMPT | 图片 / 视频 / 音频 / 提示词 | 同上 |

**三处共用这一份**：学生端列表、老师端课包配置、画布上的框体。
色调沿用画布框体本来就有的那套（`.learning-node--*` 的蓝 / 紫 / 粉），
所以学生与老师看到的是同一套语言 —— 学生端是深色主题用亮色，老师端浅色主题用对应的深色。
另外给 `icons.jsx` 补了 `image / video / music / text / spark` 五个线性图标
（原来列表里用的是 ▧ ▶ ♫ ✎ 这种字符）。
老师端每条素材多了个**类型标记**（色胶囊 + 图标 + 名字），扫列表时不用先看下拉。
⚠️ 生成框体**按模态再分一层**：它在素材表里只是一种 `material_type`（GENERATION_BOX），
不按 modality 分的话「生图框体 / 生视频框体」会显示成同一个「生成框体」。

### ③ 提示词要看得见内容

提示词素材的副标题从「点击后选择插入到哪个框体」换成**内容摘要**（超 18 字截断加 …），
鼠标悬停给出全文（`title` 属性）。取的是**真正会被插进框体的那个字段**（`snapshot.content`，
与 `insertPromptToSlot` 同源），不是标题也不是说明。

### ④ 画幅档位带同比例的小示意图

抽成纯函数 `packages/canvas/src/ratioThumb.js`：最长边统一 18px、短边按比例算并设下限
（**21:9 不会缩成一条线**）、「自动」画成虚线框表示跟随课程默认、
清晰度与时长那两行不画。
⚠️ 单独放一个 `.js` 模块是有原因的：`.jsx` 在 node 里导不进来，纯函数放这里**守卫才跑得到**。

## 五、两条设计取舍（别当没想过）

1. **本地素材单列成一项**，而不是塞进某个分组：它不属于老师配的任何一组，
   混进去会让「这一组有多少老师配的素材」这个直观判断失效。
2. **一套色三处共用**（学生端 / 老师端 / 画布）：任何一处新增类型都必须改 `materialTypes.js`，
   不要各自写一份 —— 否则「生视频框体」在三个地方会变成三种颜色。
   `p110` 里有反向自检钉着「三处同源」。
