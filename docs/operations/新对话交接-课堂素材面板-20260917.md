## 二、每条做了什么

### ① 取消「素材」大类，导航就是大分组

`packages/shared/src/canvasWorkspace.jsx`：

- 导航改成**一个分组一项**（`group:<id 或下标>`），点哪个只看哪一组；
  面板只渲染 `activeGroup`，不再把一个长列表从头滚到尾。
- **本地素材单列一项**（学生从电脑拖进画布的那些）。原来它混在「素材」面板顶上，
  现在没有那一层了，混进某个分组里会更乱。
- 一组都没有时仍给一句明确的空态（别让学生看到白面板）。
- 画布面板上那个「✦ 生图 · 1k · …」的配置芯片点进来时，会打开**有生成框体的那一组**
  （以前指向已取消的「素材」面板）。

### ② 类型要能一眼分开

新增 `packages/shared/src/materialTypes.js` —— **唯一一份**「类型 → 图标 / 名字 / 色调」映射：

| 类型 | 名字 | 色调 |
|---|---|---|
| 生成框体 · IMAGE | 生图框体 | image（蓝） |
| 生成框体 · VIDEO | 生视频框体 | video（紫） |
| 生成框体 · MUSIC | 生音乐框体 | audio（粉） |
| 生成框体 · TEXT | 生文字框体 | prompt（柠檬绿） |
| IMAGE / VIDEO / AUDIO / PROMPT | 图片 / 视频 / 音频 / 提示词 | 同上 |

**三处共用这一份**：学生端列表、老师端课包配置、画布上的框体。
色调沿用画布框体本来就有的那套（`.learning-node--*` 的蓝 / 紫 / 粉），
所以学生与老师看到的是同一套语言 —— 学生端是深色主题用亮色，老师端浅色主题用对应的深色。
另外给 `icons.jsx` 补了 `image / video / music / text / spark` 五个线性图标
（原来列表里用的是 ▧ ▶ ♫ ✎ 这种字符）。
老师端每条素材多了个**类型标记**（色胶囊 + 图标 + 名字），扫列表时不用先看下拉。
⚠️ 生成框体**按模态再分一层**：它在素材表里只是一种 `material_type`（GENERATION_BOX），
不按 modality 分的话「生图框体 / 生视频框体」会显示成同一个「生成框体」。

### ③ 提示词要看得见内容

提示词素材的副标题从「点击后选择插入到哪个框体」换成**内容摘要**（超 18 字截断加 …），
鼠标悬停给出全文（`title` 属性）。取的是**真正会被插进框体的那个字段**（`snapshot.content`，
与 `insertPromptToSlot` 同源），不是标题也不是说明。

### ④ 画幅档位带同比例的小示意图

抽成纯函数 `packages/canvas/src/ratioThumb.js`：最长边统一 18px、短边按比例算并设下限
（**21:9 不会缩成一条线**）、「自动」画成虚线框表示跟随课程默认、
清晰度与时长那两行不画。
⚠️ 单独放一个 `.js` 模块是有原因的：`.jsx` 在 node 里导不进来，纯函数放这里**守卫才跑得到**。

### ⑤ 画幅档位「布局很乱、底部对不齐」（用户看到截图后追加的）

两处原因，都修了：

1. **缩略图直接当按钮的子项** → 各档比例不一样高（9:16 高、16:9 扁），
   文字被顶到不同高度。改成装进一个**固定 18×18 的框**（`.learning-node__seg-thumb-box`），
   每档都是「框 + 文字」，标签自然落同一条线。
2. **选中态 `font-weight: 700` 把行高也改掉了** → 选中那一档的文字比别档低几像素。
   给这一行的按钮写死 `line-height: 16px`。

**怎么验的（这条是量出来的，不是看出来的）**：本机起了一个临时静态页，
用**同一份真 CSS** 渲染「修前 / 修后」两行，再用 DOM 量每个标签的 `Range` 位置：

```text
修前：[119, 125, 117, 125, 125, 121]   → 4 个不同高度（就是用户说的「很乱」）
修后：[283, 283, 283, 283, 283, 283]   → 六档完全同一条线
```

⚠️ 单看缩略图截图容易看漏第 2 条（只有被选中的那一档偏几像素）——
所以第 2 条是量出来才发现的，`p110` 里也钉住了「line-height 必须写死」。

### 第 5 条（提交作品 → 我的作品）核查结论：**已经通了，不需要改**

用户原话「点击提交作品就可以把生成出来的所有内容保存到学生的我的作品里对应的课程里」。
用生产测试账号（`student-1`）真跑了一遍提交链路：

```text
POST /api/student/projects           → 复用该课时的 DRAFT 工程
PUT  /api/student/projects/:id       → 存一份「带一张已生成画面」的画布
POST /api/student/projects/:id/submit→ 200
GET  /api/student/works?includeSnapshot=true
  · 第2课 设计主角与场景 · 我的创作 | 来源=CANVAS | AI 创意动画营（演示） › 第2课 设计主角与场景
    快照节点=1 带素材=1（那张生成出来的图）
```

也就是说：**作品会进「我的作品」、挂在对应课包/课时下、生成出来的画面在快照里**。
（这次核查在生产里留了一条 `PENDING` 作品，标题「第2课…」，**可删**。）

**但有两个真缺口**，都不是「没保存」而是「存的是引用」：
1. 「我的作品」的卡片只画一个 🎨 图标 + 标题 + 来源，**不显示那张画面** —— 内容在数据里，看不出来。
2. 快照里的素材地址是**上游的临时链接**（`https://getapib.org/…`）。生成素材在 `media_assets`
   里存的就是这个地址，**它会过期** —— 过期之后「我的作品」里的内容就成了死链。
   要真做到「所有内容都保存下来」，得在提交时把素材**转存成平台自己的副本**（下载 + 落
   `file_assets` + 改写快照地址）。这是有成本的一步，留给你定。

## 五、两条设计取舍（别当没想过）

1. **本地素材单列成一项**，而不是塞进某个分组：它不属于老师配的任何一组，
   混进去会让「这一组有多少老师配的素材」这个直观判断失效。
2. **一套色三处共用**（学生端 / 老师端 / 画布）：任何一处新增类型都必须改 `materialTypes.js`，
   不要各自写一份 —— 否则「生视频框体」在三个地方会变成三种颜色。
   `p110` 里有反向自检钉着「三处同源」。

## 六、守卫基建：剥注释别用正则（2026-09-17 踩到）

`scripts/lib/sourceText.mjs` 的 `stripComments` —— 逐字符走，字符串原样保留。

起因：`p110` 里我用正则剥注释，而 `canvasWorkspace.jsx` 有一行注释写着
「受鉴权保护的素材（/api/**）」，其中的「斜杠 + 星号」被当成了块注释起点，
一路吞到几百行之后真正的块注释结束符 —— **470 行真代码被剥掉**，
于是断言判「代码没了」，其实是被我自己的正则吃掉的。`p108` 有同样的写法，一并换掉了。

## 七、画布交互三条（同日第三次追加）

| 用户原话 | 根因 / 做法 |
|---|---|
| ①「鼠标点空白处应该是可以取消选择的，现在点开空白处没有这个反应」 | **不是「没取消」**：react-flow 点空白自己就会 `resetSelectedElements`（选中框高亮它管），留下的是**我们自己的底部编辑面板** —— `activeNodeId` 当初设计成「取消选中后沿用上一次，面板不会突然消失」。现在点空白连面板一起收掉 |
| ②「名字不够明显，颜色改成白色，格式：同学：xxx，放 logo 右边」 | 顶栏品牌块改回一行：logo + 右边「同学：xxx」（白色、12px、加粗） |
| ③「取消了连线会显示已失效，还要点个 x 才能移除，应该直接移除」 | 引用芯片原来只被标成「(已失效)」。现在连线一断**直接从输入框删掉**（连带后面的空格），并立刻 `sync()` 让父组件的提示词同步去掉 `@图片 1` —— 不然值里留着指向不存在素材的空引用，提交上去就是错的 |

## 八、⚠️ 跑守卫时的「database is locked」不是代码问题

`scripts/lib/classroomFixture.mjs` 用的是**同一个 SQLite 库**。开发机上同时开着
vite + `apps/server/src/index.js` 时，两者抢库，守卫会随机以
`Error: database is locked` 失败（实测：p21 三连跑「通过 / 失败 / 失败」，单跑多半通过）。

判断口径：**同一条守卫单独跑能过、连跑时偶发失败 → 是抢库，不是回归**。
要干净地跑全量，先把本地开发服务停掉（或给守卫换一个库路径）。
别为了让它变绿去改守卫逻辑 —— 那是把噪声藏起来。
