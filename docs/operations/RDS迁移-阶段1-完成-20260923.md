## 二、方案里被实测推翻 / 更正的三处（**请以这几条为准**）

### ① 「转换期 await 只进微任务、不会交错」——**不成立**（这条最重要）

方案里那次实测测的是**宏任务**（`setImmediate` 的回调会不会插进来），结论对，但**不足以支撑"不会交错"**。
`await` 让出的是**微任务队列**：进程里另一个异步任务（后台 worker、定时器）只要此刻有排队的续体，
它就会在"**BEGIN 与 COMMIT 之间**"跑 SQL。实测症状：

```text
Error: cannot start a transaction within a transaction     ← aiGeneration 的 worker 与请求路径撞上（p11）
更安静的变体：别人的 INSERT 混进我的事务里、跟着我一起回滚   ← 同步时代不可能发生（同步代码一口气跑完、中间没有让出点）
```

**做法**（已落进 `schema.js`）：所有数据访问排到一条**全局队列**上；事务持有它直到 fn 跑完，
事务内部用 `AsyncLocalStorage` 认领后**保持同步执行**（否则自锁）。代价是"语句的实际执行从调用那一刻
变成拿到锁那一刻"—— 而所有调用点都 await 过（门禁 = 0），顺序语义不变。
**这是转换期的正确性机制；切到 mysql2 后每条语句各自取连接，"混进别人事务"天然不存在，这把锁可退化。**

### ② 「必须一次性改完」→ 仍然可以增量（结论没变，但理由变了）

方案说"不会交错、所以可以一个文件一个文件地改"。**交错是真会发生的**（见 ①），
但在全局锁补上之后，"一个文件一个文件地改"依然安全 —— 因为锁把交错挡在外面了。
换句话说：**可以增量**这个结论保留，但它现在依赖锁，而不是依赖"await 不让出事件循环"。

### ③ 「漏 await 会被运行时检测器当场炸」——**只对了一半**

`pendingResult` 那个 Proxy 抓得到：**属性访问**（`user.id`）、**JSON 序列化**、**迭代**（`[...rows]`）。
**抓不到**：`if (leaked)` / `!leaked` / `x && y` —— JS 的 ToBoolean 对对象**没有可拦截的钩子**
（Proxy 的 `get` 不会触发），恒为真。方案原文把 `if (user)` 列为能被抓到的形态，**写反了**。
兜住这一类的是**静态检查**（"调用 async 函数却没 await 的调用点 = 0"），不是运行时检测器。

## 三、改造中真实踩到、并已修掉的坑（都写进了工具注释）

```text
1. 前向引用：调用点写在函数声明之前（JS 提升）→ 就地查作用域查不到 → 漏 await、漏传播
   （lib.js 的 normalizeLesson 调 816 行才定义的 lessonCanvasConfig，打挂 p9-r04）
2. 跨文件/包装过的 import：命名空间式（`const seed = await import(…)`）、解构式、
   算出来的路径（`pathToFileURL(path.join(root, 'apps/…')).href`、`load('apps/…')` 包装）
   —— 认不出就整片漏改（打挂 p4-o09 / p52 / p89）
3. `entries()` 给的是 `[index, value]`：`forEach((item, i) => …)` 改 for…of 时**两个变量会对调**
   —— 语法不报错、静默算错（最危险的一种）
4. `.map` 包成 `Promise.all` 改变了**顺序语义**：`previewImport` 靠 `seenLogins` 这个 Set 累积判
   "本批次登录名重复"，并发起跑后一条都查不出来（打挂 p101）→ 改用**顺序版** `amap`
5. `f().finally(cb)` 不能写成 `(await f()).finally(cb)`：await 拿到的是**解析值**，不是 Promise（打挂 p11）
6. 数组回调的判据必须是"**回调自己是不是 async**"，不是"它访不访问数据库"
   —— 第 1 趟把 `row(` 改成 `await arow(` 之后后者就没了信号（实测漏 41 处，打挂 p119）
7. **基线里本来就是 async 的函数，调用形态是有意的**（fire-and-forget / Promise 链 / 靠外层收口），
   `await` 不许动：p105 明确要求"预热不能 await，否则老师点开课要等全班开环境"
```
