## 三、⚠️ 最可能出问题的地方（**我没在浏览器里看过**）

## 四、这轮改动里「可能被人当成 bug 报上来」的行为（其实是有意的）

修 bug 时先对照这几条，别把口径当缺陷改回去：

| 现象 | 为什么 | 备注 |
|---|---|---|
| 登录名填中文被拒（`INVALID_LOGIN_FORMAT`） | 用户口径：登录名只允许英文数字 | **老账号不受影响**（只在创建/改名时校验） |
| 改成别人已有的姓名被拒（`DISPLAY_NAME_EXISTS`） | 用户口径：同机构同角色不能重名 | 不同机构、老师与学员同名**允许** |
| 平台给机构授权后，机构看不到课包 | 授权到期日 = **机构合同到期日** | 合同过期 → 刚授权就失效（这是「同步」的必然结果）。要能用就先去改机构合同 |
| 「仅授权机构」这个选项没了 | 可见范围改成两值：公开 / 私有 | 原来那个中间态取消了；「私有」不上广场，但**授权后机构照样能用**（发布 ≠ 授权这条没变） |
| 机构成员管理/学员开通/负责老师下拉里的人数 | `/org/users` **带 page 才分页**，不带 page 仍给整表（上限 500） | 今天刚修的回归（见下节） |
| 「调整授权有效期」入口不见了 | 用户口径：有效期不需要，跟合同同步 | 守卫 p82 钉住它不再出现 |

## 六、还欠着的事（不一定是 bug，但会被问到）

- **文件安全扫描会把上传拖垮**（上一轮就发现了，仍未定口径）：
  生产用独立 `clamscan`，每次加载 108MB 病毒库、进程 RSS 峰值约 618MB；机器只有 1607MB。
  一旦有学生在创作（每个约 470MB），扫描会掉进 swap（实测 9.7 秒 → 59 秒）→ 上传超时。
  当前只是把超时从 30s 放宽到 120s 兜着。**三条路要用户定**（跑常驻 clamd / 异步扫描 / 只在发布时扫），
  我的建议是第三条。见 `新对话交接-dsh迁移-20260916-第四轮.md` 第四节。
- dsh 的**工作区预选**没做（学生现在要手动选一次工作区）。
- 学生**看不到自己未发布的作品**（我的作品页只在发布后给查看入口）。
- 生产库里还留着 3 条我造的验收记录（标题带「可删」，未发布广场），要清就删
  `vibecoding_submissions` 里那几条。
