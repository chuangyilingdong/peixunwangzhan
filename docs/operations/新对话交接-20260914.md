## 四、金额口径（最容易混，全文见 `真实三账对照-20260914.md`）

| 金额 | 含义 | 是不是真实钱 |
|---|---|---|
| 对外售价 | 「模型与算力 → 对外售价」，公告价，逐笔快照 | 否，仅观测 |
| 上游计费 COMPUTED | 合同单价 × 实际用量，自动折算 | 否，是估值 |
| 上游账单（官方接口 / CSV） | 供应商账单，账期聚合 | 是，付款依据 |
| 机构购买实收 / 许可确认收入 | 机构购买批次 + 许可事件 | 是，收入侧 |

- 来源优先级：`REPORTED` > `COMPUTED` > `ESTIMATED` > `UNKNOWN`。
- 缺用量或缺单价一律 `UNKNOWN`，**绝不按 0**；改价不追溯已记录的成本。
- 真实毛利 = 许可确认收入 − 已匹配供应商结算成本；**对外售价不进入任何收入或毛利公式**。

## 六、踩过的坑（全文见 `docs/README.md` 第七节）

- **静默失败是本项目最主要的 bug 类型**：字段没人写、范围写错、页面渲染崩，都不报错。
  规矩：改数据范围先确认**那个字段有没有被写过**；改前端必跑 `p70`；改安全范围必跑 `p69`。
- 往 SQL 里写 `//` 注释 = 全库初始化失败（SQLite 只认 `--`）。
- ESM 里 import 一个已删除的导出是链接期错误（服务起不来）。
- 别用内联 `node -e` 改多行 JSX / SQL / 含 `>` 的字符串，写脚本文件。
- 删依赖必须同步 `pnpm-lock.yaml`，否则 `--frozen-lockfile` 让构建失败且日志为空。
- 有 agent 会写出 CRLF；`git diff --check` 报 trailing whitespace 时用
  `.tmp/normalize-lf.mjs <file>` 规范成 LF（仓库约定 `eol=lf`）。
