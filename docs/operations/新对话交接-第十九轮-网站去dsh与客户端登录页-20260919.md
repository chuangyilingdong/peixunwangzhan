## 二、这一轮做了什么（按主题）

### A. 网站：**不再有 dsh**，VibeCoding 的入口改成「把学生送到客户端」

用户口径：「网站上的 dsh 就不要了，以后 vibecoding 就是在客户端进行」。

1. **删掉整个网页侧创作环境**：`packages/shared/src/runtimeWorkspace.jsx` **整份删除**（228 行）。
   那份文件是「进入创作环境」（服务端拉起 dsh 盒子、新标签页打开）＋「提交作品」的唯一实现。
2. **新的入口**：`packages/shared/src/clientEntry.jsx` —— 两个东西，
   `打开创作客户端`（`<a href="lingdong://open">`，深链叫起客户端）＋ `下载客户端`（`/download`）。
   **点不动时**（没开始 / 已完课 / 未授权）按钮文案沿用改版前那套口径（`等待开课 / 已完课 / 未授权`），
   下载入口**永远在旁边** —— 深链点了没反应只说明这台电脑没装，不能让那个学生没路走。
3. `classroom.jsx` 里的 VibeCoding 那一排换成 `<ClientEntryActions>`；`useRuntimeStatus` 这个 hook
   连同它那次 `/runtime/status` 请求一起没了（少一次请求）。
4. **样式补一条**：`.lesson-detail-action button` 那条规则**选不到 `<a>`** —— 换成链接后按钮会变成
   没有 padding/圆角/最小宽度的裸文字，所以在 `packages/shared/src/styles.css` 末尾补了一条同数值的
   `a.primary-button / a.secondary-button`。
5. 守卫口径**跟着改**：`scripts/p108-vibecoding-options.mjs` 里原来钉的是
   「入口就是『进入创作环境』+『提交作品』」与「创作环境暂不可用」，这一轮**换成反向断言**：
   网页侧不许出现 `student/runtime/(launch|deliverables|submit)`、不许有 `runtimeWorkspace.jsx`、
   深链必须是 `lingdong://open`。

### D. 客户端那个卡点：**「过门后重启一次宿主」落进代码了**（但还没在真机上验证）

上一轮的结论是「宿主在登录门之前就起来了」。这一轮**把那条链重新读了一遍**，结论要修正：

- `reconcileBackend()` 里才有 `backend.start()`（真正 spawn 宿主的地方），而它在登录门**之后**
  （`main.ts:775` 门 → `777` reconcile）。也就是说"宿主一定起在门前面"这个说法**不成立** ——
  它只说明**还有别的路径**能起宿主（更新/恢复、策略检查都会走到 `backend.start`）。
- 上一轮"写凭据文件也没用"那条实验**是无效的**：补丁层声明的是 `apiKeyEnv: PLATFORM_GATEWAY_KEY`
  （读**环境变量**），而 `refs` 里那个键**没有任何读方**。所以"写了也没用"不能当成"宿主起太早"的证据。
  （这条已在 `platform-gate.ts` 的注释里改正，别再拿它当结论。）
- **修法（已落代码）**：`runLingdongGate(createWindow, isQuitting, resetHost)` 多了第三个参数，
  在 `applyGateway()` 之后、返回 `enter` 之前 `await resetHost()`（main.ts 传的是 `() => backend.stop()`）——
  把**可能已经起来的宿主明确停一次**，后面那条 `reconcileBackend()` 会用刚写好密钥的环境重新起一个。
  宿主本来没起过时 `stop()` 是安全的空操作（`DesktopBackendController.stop()` 的语义：
  取消在途尝试、等子进程退出、允许再 start）。
- ⚠️ **这条改动只是"把机理上的口子堵上"，没有在真机上验证过**（要装客户端 + 用真学生账号 + 真课堂）。
  真机验证手法照旧：起本地验证台 → 登录 → 发一条消息 → 看 `usage_records` 与
  `session_students.vibecoding_sends`。

## 三、不许破的口径

**第十五～十八轮（19 + 6 条）全部仍然有效**（见那四份交接）。本轮新增／强化：

1. ⭐ **网站上不再有创作环境**：网页侧不许出现 `student/runtime/launch|deliverables|submit`，
   VibeCoding 的入口只有「打开创作客户端（`lingdong://open`）」+「下载客户端」。
   要动这一条，先确认客户端已经能上课。
2. ⭐ **客户端的密钥必须在宿主进程起来之前就在环境里**；宿主可能在别的路径先起来，
   所以过门之后要 `resetHost()` 停一次（`main.ts` 的门调用带第三个参数）。
3. **补丁层读的是 `apiKeyEnv`（环境变量），不是 `refs`** —— `.credentials.yaml` 里那个键是零成本保险，
   不是承重结构；别再拿它做实验然后下结论。
4. **品牌位（图标 / 字标）不许再靠手工复制或字符串替换**：图标走 `rebrand-client.mjs` 自动铺三个位置；
   字标是矢量稿，改的是"字标产地"那三个文件（boot-page / locale / ui-brand-official 的 Brand.tsx）。
5. **门那三个页面改版时，CSP 要一起放 `img-src file:`**（`default-src 'none'` 下图片被挡是静默的）。
6. **参考图里的文案是烘在图上的**：拿设计稿当素材前先确认要露出来的文字是自己渲染的
   （这一轮第一版就是真文字压在图上文字上）。
7. **网站那排按钮的样式的选择器是 `button`**：换成 `<a>` 必须补样式，否则按钮退化成裸文字。

## 六、这一轮踩过的坑（11 条）

1. ⭐ **设计稿里烘着文案**：直接把参考图裁来当素材，会把它自己的那两行标语与手绘下划线一起带进去 ——
   第一版真文字压在图上文字上（**所有断言都是绿的**，截图才看出来）。
   正解：先抹平再裁（那块是平滑红渐变，取上下两条**干净锚线**做纵向插值就接得上）。
2. **CSP 下图片被挡是静默的**：`default-src 'none'` 没放开 `img-src` 时页面照常渲染、只是那一块空白。
   判据要用 `img.complete && img.naturalWidth > 0`，别信"控制台没报错"。
3. ⭐ **别把一次阴性结果当成机理**：上一轮"写凭据文件也没用 → 所以是宿主起太早"，
   其实补丁层读的是 `apiKeyEnv`，`refs` 那条路**根本没有读方**（实验设计与结论无关）。
   这轮把机理重读了一遍：`backend.start()` 就在门后面，所以"宿主必定起在门前"不成立。
4. **Playwright 的路由是后注册的优先**：兜底 `**/api/**` 写在后面会把 `student/dashboard` 也吃掉，
   页面渲染成「暂无课程包」——**不报错**，看着像业务空数据。
5. ⭐ **模板字符串里不能写反引号**：`apply-client-gate.mjs` 的补丁文案里写了
   `` `() => backend.stop()` ``，直接把模板字符串截断了（`SyntaxError: Malformed arrow function parameter list`）。
6. ⭐ **改了签名就要有升级路径**：门调用多了第三个参数后，如果只按锚点插入，
   **旧的那一行会留在上面 → 过门两次**（登录页弹两次）。必须"原地换掉那一行"，
   并把幂等 marker 换成**新特征串**。
7. **`--dry-run` 要诚实**：升级步骤在 dry-run 下不落盘，后面的 `patch()` 读到的还是旧文件，
   会误报"已插入"。用一个 `gateInstalled` 标志把两条路串起来。
8. **网站右栏只有 128px**：一句自然断行的话会把最后一个字甩到第二行（「…下载客户端。」→「端。」），
   自己断行才好看。
9. **`button` 选择器换 `<a>` 会掉样式**：`.lesson-detail-action button{min-width:104px;…}` 选不到 `<a>`，
   补一条同数值的规则（别指望 `primary-button` 那个类够用 —— 它管的是颜色，不管尺寸）。
10. **判断"CSS 生效没有"别用 `backgroundColor`**：登录页的底色写在 `background-image` 的
    `radial-gradient` 上，`backgroundColor` 永远是 `rgba(0,0,0,0)`（我的第一版断言就写错了）。
11. **图标与字标这两种"隐性品牌位"最容易漏**：图标是三个文件（`icon-windows/macos/icon.png`）
    要一起换、且原来靠手工复制；字标是**矢量稿**，字符串替换一处也改不到。
    两处都改成了脚本化（`rebrand-client.mjs` 的 ⑤⑥），跑完看输出就知道换没换。
