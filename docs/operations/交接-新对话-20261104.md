### 1.6 RunningHub「试一次」的一个坑

- `compute_attempts` 里有一条：`channel-runhub-img-main` / `runninghub` / `rhart-image-g-2.5`
  → `FAILED GENERATION_PROVIDER_MODALITY_UNSUPPORTED`（2026-11-04T04:37Z）。
- 原因：后台「用当前渠道试一次」在渠道还没进任何 modality 路由时，默认用 **TEXT** 探测；
  RunningHub 适配器只支持 IMAGE/VIDEO/MUSIC，所以报 MODALITY_UNSUPPORTED。
- **不是**渠道/Key 的问题；真实图片生成走 IMAGE，不受影响。
- 新对话可顺手修：探测时按 family 推断 modality（`rhart-image-*`→IMAGE、`music`→MUSIC、
  `seedance/hailuo`→VIDEO），或先路由再试。

     - `modalityChannels.VIDEO = channel-runhub-video-main`

     清理引用它们的 `modelRoutes`/`visionChannelId`；

4. 用真实生成验证图片（文生/图生）、视频（主/备）、音乐；不要只用「试一次」的 TEXT 探测。
