# 内容工作台客户端 0.4.0 · 创作工作流与上下文 · 2026-10-26

## 一句话

在“做内容”内部接入了 `今日选题 / 爆款复刻 / 热点结合` 三条原生工作流，并补齐写作大脑、同行研究简报和长期记忆；一级入口仍保持 5 个。

## 本轮完成

### 1. 灵感工作流入口

“做内容”页新增三张工作流卡片：

```text
今日选题
爆款复刻
热点结合
```

不新增一级导航，点击后进入独立工作流页面，完成后结果自动带回“做内容”的定稿。

### 2. 今日选题

```text
输入方向（可不填）
→ 生成 3 个选题
→ 选一个
→ 选写作大脑或表达风格
→ 生成 3 个版本
→ 选一版
→ 回到定稿与六步制作
```

已接：

- `/workflows` 创建与轮询；
- `select_idea`；
- `select_brain` / `select_style`；
- `regenerate`；
- `select_copy`；
- 平台已保存的文案草稿。

### 3. 爆款复刻

支持三种桌面来源：

```text
现有文案
已转写档案
抖音单条作品链接
```

流程：

```text
确认/提取原文
→ 改写 3 版
→ 选一版
→ 回到定稿与六步制作
```

本地视频上传和“同行作品选择器”尚未接进桌面；网页工作台已有。

### 4. 热点结合

两种模式：

- 关键词联网搜索：调用服务端 `/workflows`，搜索由 DeepSeek Search API 执行；
- 手动填写热点：只引用用户填写的事实，不编造新闻细节。

流程：

```text
找热点 / 手填热点
→ 选结合角度
→ 选写作大脑或风格
→ 生成 3 版
→ 选一版
→ 回到定稿与六步制作
```

### 5. 文案大脑 / 同行研究简报

“做内容”页新增入口：

```text
文案大脑 · N
长期记忆 · N
```

能力：

- 查看已有写作大脑；
- 查看思考框架、方法和章节；
- 从已转写作品新建写作大脑；
- 选择 `peer_report` 时生成同行研究简报；
- 删除大脑；
- 蒸馏运行中自动轮询刷新；
- 新完成的写作大脑会进入工作流“选写法”阶段。

### 6. 长期记忆

支持：

- 新增长期记忆 / 灵感；
- 查看最近记忆；
- 删除；
- 写入平台 `/memories`，后续聊天和创作上下文继续使用。
