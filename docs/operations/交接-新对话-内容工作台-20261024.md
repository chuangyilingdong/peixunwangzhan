## 距离原版真正 100% 还差什么

核心工作流已经进 junshi；下面这些不是写 UI 能补的，需要外部服务/授权：

1. **真实视频生成**：原版接 Metaso H3 / Seedance；现在只出可拍脚本 + SRT，没有渲染服务。
2. **数字人口播**：需要人物/音色授权 + GPU 或云服务。
3. **抖音自动采集/登录/追踪**：原版用 Playwright + 登录态；需要平台授权、频率限制、登录态管理。
4. **1:1 视频复刻**：换产品/人物/背景/音色，需要 ASR + 分段 + 生成/合成链路。
5. **多创作账号切换 / 素材文件夹**：当前是一个机构一份工作台档案、素材扁平列表。
6. **激活/计费**：原程序的商业系统，**不复刻、不绕过**；junshi 用平台现有账号体系。
