**① 上游实扣接入（Seedance 直连）**
- 认清上游的回执信封：`data.usage` / 顶层 `usage` / `task.usage` 三处；

**② 文本渠道（以前一直没配价）**
- 上游价目表是「元 / 百万 token」，而字段单位原来是「分 / 千 token」→ **0.2 分填不进去**，
  所以文本渠道此前根本没法配价。已改成 **`inputFenPer1MTokens` / `outputFenPer1MTokens`（分/百万）**，
  deepseek-flash 高峰价 = 200 / 800，正好整数；旧的「1k」字段名不再被接受（p90 钉住）。
- **逐笔成本保留分以下小数（4 位），不按整数分取整**：DeepSeek 一次课堂对话约 0.2~0.4 分，
  取整会把每一笔都记成 0、整节课的文本成本凭空消失。
- 生产实测：文本那笔 `cost_source=COMPUTED`、`upstream_cost_fen=0.3678`。

## 四、金额四类口径速查（最容易混）

| 金额 | 含义 | 是不是真实钱 |
|---|---|---|
| 对外售价 | 公告价，逐笔快照（`sale_price_fen`） | 否，仅观测；**换成了机构/学员看到的「消耗」** |
| 上游计费 COMPUTED | 合同单价 × 用量证据自动折算 | 否，估值 |
| 上游实扣 REPORTED | 上游回执里的实际扣款（Seedance 逐笔给） | 是 |
| 上游账单 / 核销 | 供应商账单匹配（本平台上游**没有**账期账单接口） | 是（按账期开票的上游才用得上） |
| 机构购买实收 / 许可确认收入 | 收入侧 | 是 |

来源优先级 `REPORTED > COMPUTED > ESTIMATED > UNKNOWN`；缺用量或缺单价一律 UNKNOWN，**绝不按 0**。
文本渠道**没有**任何外部数字可印证（DeepSeek 无账单接口，余额只有 0.01 元精度、非逐笔更新），
只能靠按官方价目表填的合同单价 —— 打算改文本单价时记住这一点。

## 七、本会话踩过的新坑（都写进代码注释或文档了）

- **跨文件系统 rename**：服务器 `/tmp` 是独立挂载的 tmpfs，临时目录写 `/tmp`、产物 rename 到上传目录
  → EXDEV 失败，而且被 `catch` 静默吞成「转换失败」。临时目录必须与产物**同盘**。
- **上传目录属主**：root 留下的目录会让服务（ai-kids-prod）EACCES；且 `mkdir` 若在 try 之外，
  会冒成 **500 内部错误**，而正确表现是干净的「无法预览」。
- **`sites-enabled/iicili.cyou` 不是 `sites-available` 的软链**（两份独立文件）→ 改 nginx 要改两份，
  否则 reload 成功但完全不生效。
- **重建表会把索引一起带走**：复合唯一索引必须**在重建之后**再建一次，否则唯一性静默失效
  （迁移验证脚本当场照出来了）。
- **守卫不能假绿**：p94 第一版没跑种子数据，插入验证被静默跳过 —— 看着「通过」，其实什么都没验。
- **内联 `node -e` 做含引号的替换又翻车两次**：改用脚本文件（`Edit` 工具或 `.tmp/*.mjs`）。
- DeepSeek 余额 `GET /user/balance` 只有 **2 位小数、且不是逐笔更新**（实测一次 1882 output token
  的调用余额纹丝不动）→ 做不了逐笔校验，只能隔几天看大额变化。

- **PPT 预览/下载不能各写一份解析器**：已收敛到 `packages/shared/src/deckSpec.js`；否则 layout 推断、数组截断和图片下标会漂移。
- **PowerPoint 的 `normAutofit` 会掩盖小字问题**：XML 里写 12pt 不代表最终仍是 12pt；必须给表格、流程和来源设置硬字符预算，并做真实 PowerPoint 渲染验收。
- **视觉验收不能只看图表页**：第一版新图表/表格通过，但旧封面/章节/正文仍有大空白；13 页样例经过三轮定点修复才全部通过。
