# 内容工作台客户端 0.6.0 · 管理面补齐 · 2026-10-27

## 一句话

素材库、任务中心、内容方案库、周期计划已接入原生客户端，全部从“做内容”上下文区进入，一级入口仍为 5 个。

## 本轮完成

### 1. 素材库

- 展示图片、音频、视频和文件素材；
- 显示文件所在文件夹、大小和创建时间；
- 支持上传图片、音频、视频；
- 支持下载到本地；
- 制作方式中的形象照/音色/复刻视频共用同一素材数据。

### 2. 任务中心

- 展示最近 100 个任务；
- 显示类型、状态、时间、错误原因和重试次数；
- 失败任务可直接重试；
- 任务数据也用于首页最近任务与统计。

### 3. 内容方案库

- 展示待确认与已提交制作的方案；
- 查看完整口播和画面提示词；
- 未提交方案可“继续制作”，直接进入已有方案确认页；
- 复用 0.3.2 的方案预检、编导稿、渲染和发布包链路。

### 4. 周期计划

- 生成 7 天周期计划；
- 生成中自动轮询；
- 查看每天的内容类型、选题、目的与推荐理由；
- 确认计划；
- “用这个选题做内容”会把选题、目的和推荐理由带回“做内容”生成器；
- 确认周期计划本身不会创建视频任务或产生渲染费用。

### 5. 上下文入口扩展

“做内容”顶部现在可进入：

```text
文案大脑
长期记忆
素材
方案
周期
任务
```
