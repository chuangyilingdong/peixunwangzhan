## 三、不许破的口径

**第十五轮那五条**（授权次数不是算力额度 / 额度只观测不拦人 / 内部成本口径不上公开面 / 取消授权只有平台端 /
上游余额只有平台端能看）**与第十六轮那六条工程口径**全部仍然有效（见两份前作）。
这一轮又长出这批，同样是"踩过之后才写下来的"：

1. **课程广场（`/marketplace`）没有任何筛选** —— 那两个「画布 / VibeCoding」分类**属于灵动作品**。
2. **学生端「我的课程」=`/learn` 那一个**（`/my-courses` 只留重定向到 `/learn`，别删那行重定向）。
3. **学生页面未登录一律去 `/login?as=student`**（`/learn*`、`/my-*`）—— 落到 `/login` 会走默认的机构/老师那一支。
4. **网络层失败（`fetch failed` 那类）文案 = 「服务器繁忙，请重试一下。」**；我们自己的超时仍是「AI 服务响应超时」
   （所以那条新分支**必须排在 TIMEOUT 之后**）。
5. **顶栏下拉必须会自己收起**：路由变化、Esc、点空白，三条都要（`showStudentMenu` 在 `App` 里，路由变化不会自动关）。
6. **按钮分两套**：黑底用 specular（WebGL，只黑底可见）；浅底用药丸实心。**遮罩类效果别用在暗底长文案上**（见 §七.1）。
7. **别用已被全局样式命中的标签名**（`footer` 等）做新组件 —— 卡片底部写成 `<footer>` 会被全局页脚样式撑到 108px。
8. **改守卫断言前先看它还在不在真的断言**（第十六轮那条的延续）：这一轮又遇到一次"断言失效/误报"（见 §七.6）。

## 七、这一轮踩过的坑（都值钱，别重复）

1. **"本地全绿"≠"与生产对齐"**：我把首页数据区兜底"对齐"成了 `11 门 / 87 节`，**发布后打线上才发现线上 CMS 是
   `3 门 / 48 节`** —— 我改反了方向（原来是 `CMS_FALLBACK` 那份才对）。根因：p115 跑的是**全新种子库**，
   那里的"CMS 内容"就是种子，两个兜底一致它就绿，**它看不见生产 CMS 里那份不同的数字**。
   **纪律：涉及生产数据的口径，必须打线上量一次。**
2. **参考稿给的交互别自己"优化"掉**：我嫌参数藏起来看不到、改成常显，用户当场指出「跟参考稿完全不一样」——
   那个悬停下拉正是这个组件的核心。
3. **用户一条消息里连说几件事时，"第 N 条"未必对应我正在改的那一页**：我把「筛选就分两个板块」做在了**灵动课程**上，
   其实说的是**灵动作品**。判据要看上下文（那条消息里第 2/4 条都在说灵动作品）。
4. **两页同名/长得像时，以用户截图里的 URL 为准**：两个「我的课程」我留反了一次，来回改了两版。
5. **偶发守卫红项是一个「类」，不是一条**：`busy_timeout` 只修了一半（它写在 `journal_mode` **之后**，
   而 `PRAGMA journal_mode = WAL` 自己就要抢写锁 → 最危险的那句在裸奔）；修完又冒出
   `duplicate column name`（`if (不存在) ALTER` 的 TOCTOU）与 `UNIQUE constraint failed`（并发补种 INSERT）。
   **真根因：`schema.js` 在 import 时跑全量迁移，多个进程各跑一遍。** 尺子：`.tmp/verify-startup-race.mjs`
   （同一条库路径同时起 4 个进程 import schema.js，8 轮 = 32 次）。**正解是跨进程锁，别再加 pragma。**
6. **断言要跟 DOM 结构解耦**：首页标题从 `span/em` 换成 MaskedHeading 之后，p115 用 `.hp-title span` 取文案
   把标题**读成了两遍**，还误报成"口径③：清空了还在显示"。（撤回之后又改回来了；教训是别用位置选择器取文案。）
7. **组件媒体的"故意放大"不是装饰出血**：MaskedHeading 的 `fillScale` 会撑出 208px 横向可滚动溢出，
   该裁（`overflow:hidden`）但要认准原因是"效果要余量"，别去改装饰。
8. **文案映射前先确认"这是不是我们的代码"**：用户截图里的「进阶挑战 / 小提示」全仓搜不到 ——
   那是**独立的 dsh 创作环境**，不在这个仓里；乱改会改错对象。`已添加「${box.title」…` 才是我们的。
9. **一个"残留"往往不止一个**：第十六轮报过的 8787 旧后端（9/17 启动、默认端口、跑旧代码）这一轮**还活着**
