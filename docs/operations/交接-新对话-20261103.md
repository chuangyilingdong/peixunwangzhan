### 1.4 结束课堂自动补交（2026-11-03）

**画布（平台侧闭环）**

- 老师确认结束（`submissionCheck`）时，用 `student_projects.canvas_snapshot`（服务器最后一次自动保存）
  自动提交缺交作品。
- 自动作品：`auto_submitted=1`、`copyright_confirmed_at=NULL`；老师能看到、能点评，**不能直接进广场**。
- 无新产出 / 空画布 / 已发布 / 已评分 → 跳过；单个失败不影响结束课堂。
- 结束响应带 `canvasAutoSubmit` 数量；老师端提示「已自动提交 N 名学生的画布作品」；作品列表显示「· 自动提交」。

**VibeCoding（平台侧已就绪，等客户端）**

- `POST /api/student/runtime/submit-upload` 新增可选 `sessionId` + `autoSubmit: true`。
- 课后 **10 分钟**宽限（`RUNTIME_AUTO_SUBMIT_GRACE_MS`，默认 600000ms，夹在 1 分钟~1 小时）。
- 只认 ENDED 且结束在窗口内、名单内（REMOVED 不算）、VibeCoding 课时的课堂。
- `autoSubmit=true` 允许 `copyrightConfirmed=false`；落库 `auto_submitted=1`、版权未确认。
- 手动交过的作品**不会被自动覆盖**（`autoSubmitSkipped=true`）；自动交过且内容没变也不重复加轮次。
- 错误：`400 AUTO_SUBMIT_SESSION_REQUIRED` / `403 AUTO_SUBMIT_WINDOW_CLOSED` / `403 AUTO_SUBMIT_WRONG_CLASSROOM`。
- 迁移：`51-auto-submit-mysql.sql`（`works.auto_submitted` + `vibecoding_submissions.auto_submitted`）。
- 守卫：`p204`。
- 客户端契约：`docs/architecture/课堂结束自动提交-客户端契约-20261103.md`。
