## 三、只有真部署才能发现的两个 bug（都已修并上了线）

1. **sudo 在生产上根本不可用**。平台服务的单元里有 `NoNewPrivileges=true`，那个标志会让 sudo
   拒绝提权（原文：`The "no new privileges" flag is set, which prevents sudo from running as root`），
   跟 sudoers 怎么写无关。第一次真部署 `/deliverables` 报 500 就是它。
   **改成 root 常驻的「特权代理」**（`dsh-host-broker.mjs` + systemd 单元）：
   加固一个都没关、也不再依赖 setuid；socket `0660` 属组 `ai-kids-prod`；
   op 只有 launch/stop/collect，**脚本路径写死在代理里**；参数过校验。
   旧的那条 `/etc/sudoers.d/dsh-students` **已撤掉**（备份在同目录 `.removed-*`）。
2. **代理的产物名校验不允许斜杠** —— 我写模式时手一抖成了 `[^\\/\0]`，而平台传的正是
   工作区相对路径（`deck/演示文稿.pptx`），错误文案却写着「必须是工作区内的相对路径」。
   网页作品因为名字扁平（`index.html`）才没踩到，**PPT 一提交就被自己的代理拒了**。
   已把校验抽成纯函数 `broker-policy.mjs` 并在 `p100` 里逐条钉住（p100 现在 39 项）。

## 四、⚠️ 一个还没解决的生产问题：这台机器**内存不够**，文件扫描会把上传拖垮

实测（2026-09-16）：

```text
内存总量 1607MB；两个学生环境就占约 940MB；一个 clamscan 进程 RSS 高达 618MB
→ swap 用到 1007MB → 手动 clamscan 从 9.7 秒退化到 59 秒
→ 平台里的 30 秒扫描超时必然触发 → **所有文件上传间歇性失败**
   （学生看到的是一句「文件安全扫描超时，上传被拒绝」）
```

生产配的是 `FILE_UPLOAD_SCANNER=/usr/bin/clamscan` —— **独立**扫描器，每次调用都要重新
加载 108MB 病毒库（冷启动 16–40 秒、热缓存约 10 秒）。这条路在这台机器上注定不稳。

本轮先做的：把扫描超时从 **30s 放宽到 120s**（可用 `FILE_UPLOAD_SCANNER_TIMEOUT_MS` 调），
并在**空闲**的机器上验通了「图能存、PPT 能交、PDF 能转」。但这只是把功能性失败压回去，
**没有解决根因**。三条路要你定一条：

| 方案 | 代价 | 说明 |
|---|---|---|
| 跑 `clamd` 常驻，`FILE_UPLOAD_SCANNER=clamdscan` | 常驻内存约数百 MB（这台机器吃紧） | 扫描降到毫秒级，但等于再挤掉一个学生环境 |
| **异步扫描**（先存后扫，扫出不干净再删+标记） | 要改安全模型 | 用户侧不再等，最贴合「上课时不能卡」；要接受「文件先落盘再判」 |
| 只在**发布到作品广场**时扫 | 最小改动 | 学生提交不再等扫描；公开前把关（发布是平台点的一次性动作） |

我的建议：**先走第三条**（把扫描从「提交」挪到「发布」，改动小、对症），
等机器扩容或换扫描器再考虑常驻 `clamd`。**但这条会动安全模型，所以留给你定。**

## 五、其它要你知道的（都不是阻塞）

- **宿主的 `remote.origin.fetch` 只配了 `main`** —— 在特性分支上 `git pull` 是**静默空转**
  （报「Already up to date」，其实什么都没拉）。这轮发布时踩到，已就地补上 refspec；
  换机器/重装要记得（`git config remote.origin.fetch '+refs/heads/*:refs/remotes/origin/*'`）。
- **内存现状**：我把上一轮那个预览环境（`dshs-cc43a8fc3e`）也收掉了 —— 它闲置占着约 470MB，
  而这台机器一直在 swap。现在机器上没有学生环境（可用内存回到约 1.3GB）。要再看 dsh 界面，
  让学生点一次「进入创作环境」就会重开。
- 「设置不落盘」那条（第三轮列过）**仍然是反证状态**，没进一步验。
- 学生**看不到自己未发布的作品**（我的作品页只在发布后给查看入口）—— 与老链路行为一致，
  但对 dsh 交上来的 PPT 来说体验更差一点（连下载都没有）。要不要给学生一个自看入口，等你定。
