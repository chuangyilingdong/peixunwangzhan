# 新对话交接 · 课堂按线框图改造（2026-09-17）

> 教师端「我的课堂」原来是一个 36KB 的 `Classrooms.jsx`（列表 + 详情 + 创建弹窗 + 添加学生
> + 四个确认弹窗全挤在一起），本轮按用户给的 8 张线框图改成**四个独立路由**，
> 顺带统一了两个后台应用的字体、清掉了根目录的垃圾文件。
> 生产发布记录见最后一节。

## 一、这轮改了什么

| 路由 | 线框图 | 关键改造 |
|---|---|---|
| `/classrooms` | 005-01 | 四张状态卡（**取自服务端计数**，不再「本页里数一数」）+ 补上课包/课程筛选与查询/重置 + 表格拆出创建/实际开始/实际结束 + 真分页 |
| `/classrooms/new` | 005-02 | 创建从**弹窗改成独立页**：左表单、右「所选课程摘要 + 创建规则」、底部「保存后的业务链」四步 |
| `/classrooms/:sessionId` | 005-03 ~ 03E | 双栏「课堂信息 / 课堂操作」、课包课程「已锁定」、名单改九列、四个带影响说明的确认弹窗 |
| `/classrooms/:id/students/new` | 005-04 | 添加学生从「详情页往下滚的一段」改成独立页 + 可加/不可加标签页 + A/B/C 判定说明 |

代码落点：界面在 `apps/org/src/pages/classroom/`（7 个文件），
路由壳留在 `apps/org/src/pages/Classrooms.jsx`（只做分派与导航）。

## 二、三个口径是用户当场定的（别自己改）

1. **数据缺口只补两个后端缺口**：列表分页与总数、开始/解散的预检接口。
   学生的「课包授权状态：学习中/待激活」与课堂的「创建账号」**现在数据库里根本没有**，
   按用户口径**改用我们真有的口径**（许可 / 算力池 / 参与状态），**不假装**。
2. **「不可添加学生」保持 2026-09-16 的原口径**：标签页做、数字显示，但**不铺姓名**，
   只在搜索命中时连原因一起显示（线框图要求整列铺开，与那条口径相反，用户选了保持原口径）。
3. **「更换课包·课程」本轮不做**。后端 `PUT /api/org/sessions/:id` 支持（带 `confirmClearStudents`），
   但代价是把现有名单全部置为已移除，用户选本轮不暴露这个入口。

## 三、后端只动了两处

### 3.1 `GET /api/org/sessions` 补真分页与四态计数

之前是**硬编码 `LIMIT 200`、不返回总数** —— 界面上做不出「共 N 条 / 翻页」，
超过 200 个课堂的机构还会**静默**看不到后面的（本项目最主要的失败类型）。
现在返回 `items / total / page / limit / totalPages / statusCounts / ongoingSession / filters`。

⚠️ **状态过滤是单独拼的**：四张汇总卡要的是「不带 status 过滤」的口径，
否则选中某个状态之后另外三张卡会全部归零，看着像数据丢了。

### 3.2 新增 `GET /api/org/sessions/:id/precheck?action=start|dissolve`

线框图的确认弹窗要逐条显示「✓ 通过」，而这些检查原来只散在各个 POST 的 `throw` 里。
前端凭详情字段推，其中**「老师账号是否可正常教学」「N 名学生资格是否仍有效」两条根本推不出来**
—— 在界面上给一条没真跑过的检查打绿勾，就是在撒谎。所以判定挪到服务端。

- start 五条：`SESSION_PENDING / TEACHER_READY / LESSON_AVAILABLE / ROSTER_NOT_EMPTY / STUDENTS_ELIGIBLE`
- dissolve 三条：`SESSION_PENDING / NOT_STARTED / OWNER_MATCH`
- ⚠️ 它**只读、只给界面看**：真正的写操作仍以 POST 里的断言为准（预检通过后状态可能已被别人改了），
  界面上的按钮也只是「不通过就不让点」，预检不是放行凭据。

## 四、⚠️ 浏览器实点抓出来的四个问题（只看代码一个都发现不了）

我用真 Chrome 把四个页面逐页点了一遍（截图在 `.tmp/classroom-ui/`），当场抓出：

1. **创建页在说谎**。它无条件显示绿色的「当前账号无待上课/上课中课堂，可以创建新的课堂」，
   可同一时刻列表页说有一个 —— 我把文案写死了，没按真实占用算。现在读 `statusCounts` 判断，
   占用时给橙色提示并禁用「保存课堂」。
2. **红色按钮失效**。`Classrooms.css` 在 `main.jsx` 里**先于** `@platform/shared/styles.css` 求值，
   同优先级时共享样式在后、会赢 —— 「解散课堂」的红色描边被 `.secondary-button` 盖掉了，一直是灰的。
   → 新增的覆盖类一律带 `.classrooms-page` 前缀（见 `Classrooms.css` 里的注释）。
3. **漏了四个小标题**。线框图里「保存后的影响 / 确认移除后的影响 / 确认开始后的状态变化 /
   确认解散后的状态变化」这几段，我只画了内容格子、没画标题。
4. **规则文案和数据互相打脸**。线框图说「已解散不产生实际开始/结束时间」，
   但这个平台解散时**确实会写 `ended_at`**；表格里显示着时间、下面的规则却说没有。
   现在那一格标明是「解散时间」，规则文案改成实话。

另外：列表九列被挤到「操作」列出可视区（三个时间列用完整日期占太宽）→ 换成线框图本来的
`09-15 09:40` 紧凑格式，完整时间挂 `title`；确认弹窗比线框图长（多了「状态变化」与
「不会发生的事情」两段），「确认解散」要滚动才够得着 → 操作行改成吸底。

## 五、后台字体统一（用户口径：「后台全部用画布课堂那个字体」）

画布课堂的字体栈在 `packages/shared/src/styles.css:1173` 的 `--cv-font`
（`'Geist', 'Noto Sans SC', …系统字体兜底`），dsh 控制台的 `--font-sans` 也是同一套。

**根因不是「栈不一样」，而是那两个 webfont 在机构端从来没加载成功**：
共享样式表用**根绝对路径**引 `/fonts/Geist-*.woff2`，而 `apps/org`、`apps/admin`
**根本没有 `public/` 目录** → 整个后台一直在 404、静默回退系统字体
（构建时那句 `didn't resolve at build time` 就是它，很容易被当成噪音刷过去）。

- 字体文件补到 `apps/org/public/fonts` 与 `apps/admin/public/fonts`
  （与 `apps/website/public/fonts` 同源同内容；**git 对相同内容只存一份 blob**，仓库体积几乎不涨）。
- 字体覆盖只在两个**后台**应用：`apps/org/src/theme.css`、`apps/admin/src/admin.css` 末尾，
  规则是 `:root, body { font-family: var(--cv-font); }` —— **引变量，不再抄一遍字体清单**。
- ⚠️ **学生端（`apps/website`）不动**：它自己的 `:root` 另有一套口径，且是在共享样式之后导入的。

## 六、守卫的改动（三处，都是有意的）

| 守卫 | 改动 |
|---|---|
| `p81-classroom-interaction-guard` | 拆页面后断言跟着契约换文件：导航三处仍在 `Classrooms.jsx`；两个 `SearchSelect` 与上课类型判断挪进 `pages/classroom/`。`lesson?.deliveryModes?.length` 随 `publishedModes` 收口到 `states.jsx`。**口径没变，只是落点变了** |
| `p70-pages-render` | 扫描目录补上 `apps/org/src/pages/classroom`（原本是非递归 `readdirSync`，不列出来新页面完全没覆盖）。为此给 `ui.jsx` 的 `BoundaryNote/RuleList/Checklist` 加了默认空数组、`ClassroomWork` 的 `work` 默认 `{}` |
| **`p111-classroom-ui-check`（新增）** | 真浏览器守卫，见下 |

### p111 是什么

起临时库 + 真 server + `vite preview` 出构建产物，用**真 Chrome** 登录教师端，
逐页断言「**页面上真有那句话**」（空白页也算失败）并截图到 `.tmp/classroom-ui/`。
第四节的四个问题全都是它抓出来的。

它同时钉住两件容易回归的事：后台字体必须与画布同一套（`document.fonts.check('16px Geist')`
必须为真，不只是「不 404」）、以及**任何 4xx/5xx 都算失败**（曾经为字体 404 留过一条豁免，
字体修好后已撤掉 —— 留着它以后真回归了会被静默吞掉）。

⚠️ 依赖 Chrome（与 `scripts/verify-production-entrypoints.mjs` 同一套口径，`CHROME_PATH` 可覆盖）；
⚠️ `vite preview` 只绑 `::1`，探测与访问都要用 `localhost` 而不是 `127.0.0.1`。

## 七、还没做的 / 别误以为做了

1. **「更换课包·课程」没有界面入口**（用户定：本轮不做）。详情页蓝色提示里
   **没有**照抄线框图那句「如需更换，必须先移除全部学生」—— 那句话会让老师到处找一个不存在的按钮。
2. **学生的「课包授权状态」与课堂的「创建账号」没有数据来源**（没有列、没有字段），
   界面按真实口径替代，**没有编字段**。要做到线框图那个样子需要改 schema。
3. **`教学版本` 用的是 `series.version`**（课包版本，如 v1.0）；
   线框图的「环境类型：AIGC」我们没这个概念，换成真实的上课类型（画布课堂 / VibeCoding 课堂）。
4. **线框图里那套「005-01」之类的编号没有进界面**：那是线框图自己的图纸编号，不是产品文案。
