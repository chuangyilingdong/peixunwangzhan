# 100 并发容量评估与压测手册（2026-11-12）

> 结论口径：**100 人同时在线上课**（文本对话/画布浏览）在带宽升级与控制面优化后具备基础，需压测确认；
> **100 人同时交 20MB 作品/同时生成视频**受上传闸与归档收敛时间约束，按“2–3 分钟批次收敛”设计，不承诺瞬时完成。

## 一、实测底数

| 项 | 实测 |
|---|---|
| ECS | 4 vCPU / 7.4GB 内存 / 磁盘 40G 已用 69%（剩 12G） |
| 入向带宽 | 8 路并发 **19.0MB/s ≈ 159Mbps**；单流 18.2MB/s |
| 出向带宽 | 到外网测试点 **≥10MB/s（≈80Mbps）**，路径相关 |
| 应用 | 单 systemd 进程、单 Node 进程 |
| RDS | MySQL 8.0.36，buffer pool 3GB，max_connections 1720；**基线 82 条连接（含另一个应用）** |
| 应用 DB 池 | `MYSQL_POOL_SIZE` 默认 10 |
| nginx | 4 worker × 768 连接；HTTP/2 + upstream keepalive 已开 |
| 当前真实峰值 | 约 4.6 rps（278 请求/分钟），293 IP/天 |

2026-10-30《方案-1000并发H3生成》里的 5Mbps 是旧基线，已过期。

## 二、100 人容量账（按实测带宽）

| 场景 | 计算 | 判断 |
|---|---|---|
| 100 人各交 20MB | 2GB ÷ 19MB/s ≈ **105 秒** | 带宽够；上传闸 1 并发 + 60s 等待会 429 |
| 100 条 20MB 视频归档 | 2GB ÷ 19MB/s ≈ **105 秒** | 归档 3 路、单流 18MB/s，带宽够 |
| 100 人首屏静态资源（约 2.5MB/人） | 250MB ÷ 10–19MB/s ≈ **13–25 秒** | 可接受；CDN 更快 |
| 100 人画布轮询 | 约 40–60 rps、200–300 DB QPS | 需压测；池 10 有排队风险 |
| 100 路 SSE | nginx 3072 连接上限内 | 平台侧可行；上游 QPS/预算另算 |
| 100 人同时生成图片（1–2MB） | 100–200MB，约 **5–10 秒**收完 | 可行 |

## 三、当前硬约束

1. **上传闸**：`RUNTIME_JSON_MAX_INFLIGHT=1`、等待 60s；下课 100 人同时提交，99 个会 429。
   - 短期：调到 2–4 份、`RUNTIME_JSON_GATE_WAIT_MS=180000`；
   - 中期：客户端预签名直传 OSS，绕过 Node 内存与入口。
2. **DB 池 10 + RDS 共用**：RDS 还有另一个应用 `aicyld_main` 与运维连接；100 并发轮询/上传需压测后把池调到 20–30。
3. **单点**：单 ECS/单 Node；发布/重启/崩溃 = 全班中断，无 HA/滚动发布。
4. **磁盘 12G 空闲**：100×20MB 临时文件（归档 3 并发约 60MB）没问题，但备份/release/日志需保留策略。
5. **上游**：“不限并发”要再确认 QPS、账号任务数、预算；无限并发 ≠ 无限 QPS/费用。

## 四、压测工具

```bash
# 轮询（先准备一个学生 token）
BASE_URL=https://aicyld.com LOADTEST_TOKEN=... VUS=100 DURATION_SEC=60 SCENARIO=poll \
  node scripts/loadtest-100.mjs

# 下课提交 burst（该学生需有一节进行中的 VIBECODING 课堂；会真实写作品）
BASE_URL=https://aicyld.com LOADTEST_TOKEN=... VUS=100 DURATION_SEC=60 SCENARIO=upload UPLOAD_MB=20 \
  node scripts/loadtest-100.mjs

# 混合（80% 轮询 + 20% 上传）
... SCENARIO=mixed UPLOAD_RATIO=0.2

# 画布任务轮询
... LOADTEST_PROJECT_ID=<projectId>
```

输出：每端点的 count/errors/p50/p95/p99/max、状态码分布、总 rps，以及开始/结束的
`/__metrics`（RSS、DB 池等待、SSE 活跃、归档队列、网卡速率）。结果写到 `.tmp/loadtest-*.json`。

`/__metrics` 只在服务器本机可访问：

```bash
ssh ai-kids-prod 'curl -s http://127.0.0.1:8789/__metrics' | jq
```

## 五、验收阈值（建议）

| 场景 | 通过线 |
|---|---|
| A. 100 VU 轮询 10 分钟 | p95 < 800ms、错误 <1%、ECS CPU <70%、DB `waitMsMax` < 50ms |
| B. 100 VU 交 20MB（分 0/30/60s 三波） | 成功率 ≥99%、无 5xx、总收敛 <3 分钟；记录 429 比例 |
| C. 100 路 SSE | 首 token p95 可接受、上游 429/5xx <1%、SSE active ≈100 |
| D. 100 条视频生成+归档 | 归档队列排空 <3 分钟、RSS <1.5GB、入口带宽不超 150Mbps |
