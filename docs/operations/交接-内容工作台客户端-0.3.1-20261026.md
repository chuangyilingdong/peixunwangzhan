## 本轮修复

### 1. 长文案不再拖整页

根因有两个：

- 流式输出每收到一段都调用 `output.scrollIntoView({ block: 'end' })`，会不断滚动整个 `.view`；
- 结果区没有最大高度，文案越长整张页面越高。

修复：

- 改为只滚动结果框内部；
- 结果区最高为视口可用高度，内部独立滚动；
- 用户主动向上翻看时，后续流式片段不会强行拉回底部；
- 主题输入框也限制最大高度，避免手动拖拽把布局撑坏。

### 2. 生成完成后的下一步

“做内容”生成完成后现在有明确闭环：

```text
生成 3 个版本
→ 复制文案
→ 去抖音 / 视频号发布
→ 发布后回“我的数据”同步作品
→ 生成数据建议
→ 按建议再写一条
```

结果区新增：

- `复制文案`（按类型显示复制文案 / 脚本 / 清单）
- `换一批`：带入上一版并要求换开场、结构和案例
- `发布后看数据`
- “下一步”说明卡

### 3. 数据建议 → 做内容

“我的数据”现在会在同步后提示生成建议；建议生成后出现“按建议写一条”，自动把建议带入“做内容”，并设置口播稿与咨询目标。

### 4. 同行采集与转写等待提示

- 添加同行后提示“下一步：点去采集”；
- 打开同行主页后提示在采集窗口点“采集当前主页”；
- 采集完成后提示回工作台点“参考这条写一条”；
- 转写尚未完成时显示“作品已上报，正在下载和转写”，不再是一块空白；
- 同步完成会提示结果已更新。

### 5. 生成状态不再永久卡住

- 点击“生成”后立即显示生成中状态；
- 生成连接意外 `closed` 时自动解除 busy 并提示重试；
- 停止生成后提示可以修改主题继续；
- 空结果不再假装成功。
