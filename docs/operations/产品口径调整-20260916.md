# 产品口径调整一轮（2026-09-16 · 8 项）

> 时点记录，不是口径源。领域口径以 `docs/README.md` 为准。
> 这一轮是**用户看界面提的 8 条**，全部已实现、已部署到生产（release `20260916T135412Z` / commit `7d49e6c`）。
> 每条都写了「原来什么样 / 现在什么样 / 怎么验的」。

## 一、课包可见范围：三值 → 两值（公开 / 私有）

- **原来**：可见范围是三选一 —— 上架课程广场 / 仅授权机构 / 私有。
- **口径**：用户原话「上架课程广场和仅授权机构的意义不大，定义为**公开**和**私有**。公开就代表课程广场和授权都可以」。
- **现在**：`PUBLIC` = 课程广场 + 授权机构都能用；`PRIVATE` = 不对外。
  - 老的两个值在入口处**照旧收下并归一化**成 PUBLIC（老前端/历史守卫仍传旧值，不报 400）。
  - 公开列表、课程广场的四处查询都改成 `visibility='PUBLIC'`。
  - **老库要迁移**：`course_series.visibility` 上是列级 CHECK，SQLite 改不了 → schema.js 里加了一次
    重建表（`ALL_ORGS`/`ASSIGNED_ORGS` → `PUBLIC`，幂等，执行完 DDL 里就没有旧值了）。
    生产上实测：迁移后 5 个课包全是 `PUBLIC`，公开课包列表仍有 4 个（没丢东西）。
- **验**：守卫 p40（发布 ≠ 授权那条）、p14/p52–p56/p6/p9/p11（历史用例，仍传 ALL_ORGS 也能跑）。

## 二、平台预算：要能看出「超了多少」，工作台要有明确提示

- **原来**：工作台只有「超额预警 N 场」这样的**计数**，看不出超了多少；每场课堂/每课时的报表里也没有金额。
- **现在**：
  - 每场课堂算出 `overBudgetFen`（超了多少分）与 `usagePercent`；课时维度给出 `overBudgetFen` 合计。
  - **成本有未知时给 null，不给 0** —— 用户要的是「有没有超出、超了多少」，把「不知道」显示成 0 就是骗人。
  - 工作台新增「**预算超支预警**」面板：按课时列 预算 / 已知成本 / 超出 / 涉及课堂与机构，并给一句该怎么处理；
    「运营关注」一行给出超支总额；「用量与成本」两张表加了「超出」列。
  - 预算字段本身**仍只对平台可见**（它是我们的内部成本价，机构/学生侧不出现）。
- **验**：守卫 p65（未知成本不得伪装成总成本）、p62、p79、p90。

## 三、素材编辑器：生成框体不再要求上传素材 + 版面重排

- **原来**：每条素材是一排没有标签的裸控件（标题、类型、删除、说明、内容混在一起），
  两条素材之间只有一条虚线 —— 用户原话「很多东西，只有一点点缝隙区分」；
  而且选了「生成框体」仍然要用户填「预置素材地址 + 上传素材」，很冗余。
- **现在**：
  - 生成框体的预置素材**只在图片/视频模态下才出现**（文字框体、音乐框体根本不吃素材）；
    视频模态另外会提示「这个模型不支持纯文字生视频，必须给一张首帧图」（按模型 `inputModes` 判断）。
  - 版面：一条素材 = 一张卡片（左边一道色条），头部是「素材 N + 类型 + 删除」，
    字段一律**带标签**、成组排列（`.lesson-field` / `.lesson-field-row`），卡片之间留足间距。
- **验**：守卫 p28（生成框体保存/回读形状）、p31（音乐）、p35（学生自选参数）、p76。

## 四、删掉「文字说明」素材类型选项

- **口径**：用户原话「这里的文字说明选择删除掉」。
- **现在**：类型下拉只剩 图片 / 视频 / 音频 / 提示词 / 生成框体。
  - **服务端与老数据仍兼容 `NOTE`**（schema 默认值就是它），历史课时打开时下拉里会临时补一条
    「文字说明（旧数据）」，不会显示成别的类型。
  - 新建素材的默认类型改成 `PROMPT`。
- **验**：p28/p45（文档产物与素材形状）。

## 五、平台→机构授权：不再填有效期，跟合同日期同步

- **口径**：用户原话「这里有效期不需要，跟机构创建的合同日期同步即可」。
- **现在**：
  - 创建授权、追加次数建立授权，到期时间一律取 **`organizations.contract_expires_at`**（不再写死 365 天）。
  - **改机构合同日期 → 它的有效授权跟着变**（`syncAssignmentExpiryForOrg`，在机构更新接口里调用）。
  - 「调整授权有效期」接口**已删除**，界面上的那块换成说明（要延长就去改合同）；
    守卫 p82 里加了一条 `assert.doesNotMatch(页面, /assignments\/validity/)` 防回退。
  - ⚠️ 副作用要记住：**合同已过期的机构，刚授权就等于失效**（这是「同步」的必然结果，也是对的）。
    p40 的夹具因此把机构合同改成了未来时间。
- **验**：p40、p77、p82、p85（授权与收入台账）。

## 六、账号唯一性与登录名格式

- **口径**：用户原话「创建账号时要做唯一性校验，因为不同的用户可能是同登录名或者同名字。
  而且登录名现在可以填中文，应该是只能英文、数字的」。
- **现在**：
  - 登录名：`^[A-Za-z0-9][A-Za-z0-9._-]{0,49}$`（只英文数字，可带 `. _ -`；保留这三个符号是为了
    不把 `teacher-1`、`p4-o14-student` 这类**已有账号**挡在门外）。**保留旧账号可用**。
  - 登录名唯一：**全局、忽略大小写**（`Zhang` 与 `zhang` 算同一个）。
  - 姓名唯一：**同机构 + 同角色**（不同机构可同名；同机构的老师与学员可同名）。
  - 覆盖面：机构建号、机构建管理员、平台建机构（含首个管理员）、平台建管理员、**批量导入预览逐行**、
    以及**改名**（改成已有的名字同样会被拒）。
- **验**：新守卫 `scripts/p101-account-uniqueness.mjs`（27 项：格式、大小写唯一、同机构同角色重名、
  跨角色/跨机构放行、改名、导入逐行标注、名单分页）。

## 七、教师素材在线预览全部失效（真 bug）

- **现象**：机构管理员在「课时详情」点「在线预览」，iframe 里显示
  「iicili.cyou 拒绝了我们的连接请求」。
- **根因**：站点级安全头是 `X-Frame-Options: DENY` + `frame-ancestors 'none'`，
  而预览是**在我们自己的页面里用 iframe 打开的** → 浏览器直接拒收。
  而且**应用自己也发**了一条 `x-frame-options: DENY`（`lib.js` 的 `securityHeaders`），
  所以只改 nginx 不够，两边都要改。
- **现在**：
  - 应用侧：`prepareFilePreview` 的响应显式声明 `x-frame-options: SAMEORIGIN` + `frame-ancestors 'self'`
    （只影响预览这一类响应）。
  - nginx：加了一条正则 location（优先级高于普通前缀 `/api/`），只对 `^/api/(?:org|public|student|admin)/.*preview$`
    放行同源内嵌。⚠️ `add_header` 是**子层级覆盖父层级**，所以该 location 里 CSP 必须一起重写。
  - 仓库里同步更新了 `deploy/production/nginx.conf.example`。
- **验**：生产上用**真实存在**的作品文件预览一次：`200`、`%PDF`（36151 字节）、响应头 SAMEORIGIN 且无 DENY；
  普通接口与首页仍是 DENY（没有一起放开）。

## 八、机构端学员名单：筛选 + 翻页（最新在前）

- **原来**：`/api/org/users` 固定 `LIMIT 500`，而且 `total` 是**假的**（= 当页条数），
  前端一次把整个名册铺成 checkbox 长列表。用户原话「万一有100个学生呢」。
- **现在**：
  - 服务端：真分页（`pageParams`/`pageResult`，默认 20/页，上限 200）+ 搜索（登录名/姓名/手机号），
    **最新添加的排最前**（`created_at DESC`）。
  - 前端：搜索框、分页、`共 N 条 · 第 X / Y 页`、「全选本页」、「清空选择」、「已选 N 名」，
    并把**已勾选的学员用名单列出来**（跨页选择看得见，不会授权错人）。
  - 「全选」只作用于当前页 —— 几百人的名册上做跨页全选是个陷阱。
- **验**：p101 第六节（25 个学员 → 第一页 20 条、真 total、页间不重叠、最新在前、搜索命中）；
  生产上机构管理员实测：`page/limit/total/totalPages` 齐全，搜索 `d` 命中 `student-1`。
