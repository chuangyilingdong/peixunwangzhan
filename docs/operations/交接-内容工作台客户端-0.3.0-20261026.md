## 客户端产品形态

登录后加载本地：

`apps/junshi-desktop/src/app.html`

不再打开网站 `/junshi/index.html`，renderer 不持有平台 token；API 全部通过主进程 IPC 代理。

一级入口只有 5 个：

1. **首页**：大按钮入口、同行/作品/任务概览、最近任务。
2. **做内容**：一句主题 + 内容类型 + 目标 → 流式生成 3 个版本；可停止、复制。
3. **同行采集**：三步向导 + 同行卡片 + 采集结果 + 参考仿写。
4. **我的数据**：自己作品汇总、同步入口、生成数据建议。
5. **设置**：自动同步、间隔、开机启动、通知、托盘、更新、退出登录。

## 同行采集完整流程

```text
添加同行主页
→ 点“去采集”
→ 内置抖音浏览器打开主页
→ 点“采集当前主页（同行）”
→ 本地读取作品
→ 上报平台
→ 服务器下载 + 音频分片转写
→ 转写成功的口播出现在“采集后能做什么”
→ 点“参考这条写一条”
→ 跳到“做内容”，自动带上该口播作为参考
→ 生成自己的 3 个版本
```

UI 中已有：

- 三步说明卡；
- “查看完整步骤”弹窗；
- 登录/验证码由用户手动完成的提示；
- “参考这条写一条”按钮；
- 只学习结构、不照抄原文的参考提示。

### 生产 ASR 与大文件

- 根因：整段大视频上传 Whisper 导致超时/524，且大文件 OSS 读取原为 180 秒超时；
- 改为 ffmpeg 抽 16kHz 单声道音频 + 5 分钟分片 + 每片 3 次重试；
- OSS 大文件读取超时改为 600 秒；
- 单条抖音视频上限由 120MB 提升到 200MB；
- 185.6MB 视频成功转写，时长约 695 秒；
- 135.8MB 视频成功转写，时长约 1601 秒；
- 历史任务错误已清洗，不再暴露 HTML/内部函数名。
