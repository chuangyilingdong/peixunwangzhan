# 新对话交接 · 教学素材预览（2026-09-17）

> 起因：老师点「在线预览」看不到素材，页面上回显
> `{"code":"TEACHING_ASSET_FORBIDDEN","message":"教学素材仅教师可见"}` —— 而他**就是**教师。
> 查下来是两个 bug 叠在一起，加上后来用户提的三条新要求（素材永不过期、去掉所有下载入口、新增全屏）。

## 一、为什么「教师看不到教师素材」（两个 bug 叠在一起）

### 1.1 真凶：快照把短时票据冻死了

`apps/server/src/lib.js` 的 `normalizeLesson`：课时有 `published_content` 快照时（机构端读的就是快照），
教学素材整份从快照取 —— 包括 `previewUrl`。而 `previewUrl` 里是**只活 1 小时的签名票据**。

结论：**发布 1 小时之后，这节课的素材预览永久失效。**

实测证据（用备份库只读查的）：出问题那节课的 PPT 与教案，票据到期时间 `2026-09-16 19:28`，
而用户点开是在 `2026-09-17 17:27` —— 过期 22 小时。两个素材，两个都过期。

### 1.2 让错误信息说谎的：iframe 带不了鉴权头，回落到共用的 cookie

预览开在 `<iframe>` 里，iframe **没法带 `Authorization` 头**（票据存在的理由就是这个）。
票据一失效，`routes/fileAssets.js` 的预览路由就回落到会话鉴权，于是走 `lib.js` 的 `readToken`：
**先 Authorization，再 `platform_token` cookie**。

而 cookie 是这么种的：`platform_token=…; Path=/; HttpOnly; SameSite=Lax` ——
**`Path=/` 且无 `Domain`，属于整个 `iicili.cyou`**，`/`、`/admin/`、`/org/`、`/student/` 四个端共用一份，
谁在这个浏览器里最后登录就是谁。用户浏览器里恰好是**学生会话** → `role === 'STUDENT'` →
`TEACHING_ASSET_FORBIDDEN` 抛出 → 界面显示「教学素材仅教师可见」。

> ⚠️ **这条错误码只在 `role === 'STUDENT'` 时抛出**（`fileAssets.js`），完全没登录时会先抛 401。
> 所以下次再看到它，先怀疑「这个请求用的身份不对」，而不是「这个人不是老师」。

**当时的应急办法**：在机构端重新登录一次（覆盖 cookie）→ 立刻就能看。
原因：票据虽然失效，但回落分支一旦拿到**教师**身份，`teachingAssetVisibleToOrg` 是放行的。

## 二、改了什么

### 2.1 素材随时能看（不再依赖长链接）

1. **快照不再冻结 `previewUrl`**（`lib.js` 新增 `teachingGroupsFor`）：
   标题/说明/排序仍按快照定格，但 `previewKind / previewUrl` 一律**现签**。
2. **点开素材那一刻再取一张新票据**：机构端点「在线预览」时调用
   `GET /api/org/file-assets/:id/preview-ticket`（需登录 + 同一套 `authorizeFileAccess`）。
   这样「抽屉开了几小时」也不影响 —— 不靠把票据变长命，而靠每次用的时候现签。

### 2.2 去掉所有下载/导出入口（用户列了五个）

⚠️ **那一排「下载 / 旋转 / 打印 / 保存到云端硬盘 / ⋮文档属性」是 Chrome 内置 PDF 阅读器的 UI，
不在我们的 DOM 里，删不掉。** 唯一的办法是让它整条不出现：URL 片段 `#toolbar=0&navpanes=0`
（**已用真 Chrome 实测**，见 `.tmp/pdf-toolbar/` 的前后对比图；`#page=N` 也能生效，用于翻页）。

所以 `apps/org/src/components/TeachingAssetViewer.jsx` 里：

- PDF / Office：`src = previewUrl + '#page=N&toolbar=0&navpanes=0&view=FitH'`，
  翻页靠**重新挂载 iframe**（React `key={page}`）—— 只改 fragment 不会重渲染，这个坑测过。
- 视频：`controlsList="nodownload noplaybackrate noremoteplayback"` + 禁用画中画 + 屏蔽右键。
- 整块面板屏蔽右键（少一个「另存为」入口）。

### 2.3 全屏观看（用户的主要诉求：上课就是打开这些素材在讲）

全屏的是**整个面板**，不是内容区 —— 这样全屏里仍然够得着「上一页 / 下一页 / 退出全屏 / 关闭」。
进了全屏就翻不了页的话，这个功能等于没有。

另外：Esc 在全屏时只退出全屏，不关查看器（老师按 Esc 的意图几乎总是「退出全屏」）。

## 四、还没做 / 有代价的地方（别误以为做了）

1. **Ctrl+P / Ctrl+S / 右键另存为仍然可用**。`#toolbar=0` 只让按钮不出现，拦不住键盘快捷键。
   要做到「物理上拿不到」得自建渲染器（服务端把 PDF 转成逐页图片，或引 pdf.js）——
   当前服务器上没有 `pdftoppm`/`gs`/ImageMagick，只有 LibreOffice；要做得先装系统包。
2. **不再显示「第 N / 共 M 页」**，只显示「第 N 页」。总页数原来由原生阅读器提供，它被关掉了；
   要拿回来需要服务端知道页数（装 `poppler-utils` 用 `pdfinfo`，或解析 PDF）。
3. **共用 cookie 是个双向隐患**：反过来，如果某台机器上最后登录的是教师，
   **学生端的 iframe 会以教师身份鉴权** —— 拿到 `fileId` 就有可能读到教师备课资料。
   触发条件是同一浏览器里教师登录过（教室共用电脑很常见）。这条比原来的 bug 更值得单独修一轮，
   本轮**没动**（改鉴权口径影响面大）。
4. 作品预览里的「下载原文件」按钮**没动** —— 那是学生作品的入口，与教师素材是两回事。
