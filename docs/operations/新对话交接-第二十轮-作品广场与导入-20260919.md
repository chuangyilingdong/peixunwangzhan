## 二、这一轮做了什么

### A. 作品广场按参考站重做（展示）

用户口径：「我们现在灵动作品的展示有问题，参考这个网站的展示来设计」——参考站
`ltai.cc/works-square` **也是用户自己的站**。版式照它：**类型胶囊行**（全部 + 各类型，
带图标与件数，只列数据里真有的）+ **封面卡片网格**；卡片 = 封面（左上角类型角标、
视频中间播放键、右下角品牌小字）+ 标题（单行省略）+ 日期 + 作者 + **右下角机构名**。

我们比它多的：**点开能看/能播**（参考站卡片点开没动作）+ 搜索框。看图层按类型分：
图片看大图（多张可翻）、视频播、音频播、外链类**先试 iframe 内嵌**并永远给
「打不开？在新窗口打开 ↗」的出口。

### B. 导入 476 件（`scripts/import-plaza-works.mjs`，**在服务器上跑**）

为什么在服务器上：只有它能直连那个站（本机出网受限），媒体也直接落对外目录。
- 数据源：`GET https://ltai.cc/api/ke/creation/list?size=100&page=N&isMine=0`（**公开、不需要登录**）
- 一件作品 → `student_projects` + `works`（`is_public`/`PUBLISHED`/`share_token`/`copyright_confirmed_at`
  **四样齐了才会出现在广场** —— 这是那条查询的硬条件）；+ 1 个机构 + 54 个署名账号
- 元数据塞在 `works.canvas_snapshot.imported`（那是 NOT NULL 列，本来就是放作品内容的）
- 幂等（`INSERT OR IGNORE` + 文件在就跳过下载）
- 媒体 → `/srv/ai-kids-platform/public-media/`（**release 之外**，797 个文件 1.7GB、0 失败）

### C. 媒体托管：nginx 新增 `location ^~ /media/`

脚本 `deploy/production/add-media-location.sh`（备份 → `nginx -t` → reload → 公网核验）。
⚠️ **不能复用 `/downloads/`**：那条是 `default_type application/octet-stream` + nosniff，
图片/视频会被浏览器直接拒收。服务器上装了 **ffmpeg**（apt，只用于下面的转封装）。

### D. ⭐ `.mov` → mp4（本轮最贵的一课，见 §六.1）

`scripts/remux-imported-videos.mjs`：`ffmpeg -c copy -movflags +faststart` 就地转（不重编码，
28 个文件几秒一个），转完把库里 `contentUrls` 的地址一起改掉、删原 `.mov`。
**导完必须跑它**（导入脚本的文件头里也写了）。

### E. 机构名：编的少儿编程机构（8 家）

`scripts/randomize-import-orgs.mjs`：按**作者**分配（一个作者属于一个机构，作品跟着走），
固定随机种子（重跑结果一致）。现在分布：云雀AI创意学院 95 / 小海豚编程学院 89 /
星芽少儿编程 83 / 麦田少儿科创 79 / 蜂巢少儿AI课堂 50 / 木马工坊编程 38 /
银河少年创客中心 32 / 光点少年编程 10。「灵涛AI课」已归零。

### F. 分类：只有两个，且后台可配

用户口径：「分类目前就 2 个分类：画布作品和 VibeCoding作品，图片、视频、AI播客、音乐、品牌设计
放在画布作品里，其余是 VibeCoding 分类，并且分类在后台可以配置」。
- 实现：`apps/server/src/services/plazaCategories.js`（**唯一实现**），默认表 + 后台覆盖；
  配置存 `platform_settings.plaza_category_map`（schema 里加了 ALTER，服务启动即迁移）；
  后台接口 `GET/PUT /api/admin/plaza-category-map`（**改完立刻生效、不用发版**）。
- 公开接口每个作品都带 `plazaCategory` / `plazaCategoryLabel`，前端**不自己判类型**。
- ⚠️ 后台**表单**还没画（接口与存储都通了）。

### G. 分页：每页 12 件

前端切片 + 翻页条（页码窗口、换分类/换搜索词自动回第 1 页）。用户后来要求把

## 三、不许破的口径（本轮新增 6 条）

（第 7–24 条是紧接着那一段加的，在 `新对话交接-第二十一轮-官网收口与画布微调-20260919.md` §三。）

1. **广场只放"能在我们站直接打开"的作品**：本体只有别家平台链接的**不上广场**
   （对方大多用 `frame-ancestors` 禁止被嵌，跳出去等于把流量送人）。
2. **分类只有两个**（画布作品 / VibeCoding作品），**归哪一类由服务端算**、映射后台可配；
   前端不许自己按类型判分类。
3. **媒体放 release 之外**（`/srv/.../public-media/`）+ 走 `/media/` 那条 location；
   **不许**复用 `/downloads/`（octet-stream + nosniff 会让图片/视频打不开）。
4. **导入的视频必须是标准 mp4**（QuickTime 容器 `ftypqt` 浏览器播不了）——导完跑 remux。
5. **作品的"上广场"要四样齐全**：`is_public=1` + `status='PUBLISHED'` + `share_token` +
   `copyright_confirmed_at`（缺一个广场就不显示，而且**不报错**）。
6. **广场的配色与图标是"口径"**：图标用 `icons.jsx` 的线性 SVG（不用 emoji）、
   实心紫用 `--pl-grad` 渐变。改版要连 p115 一起改。

## 六、这一轮踩过的坑

（第 12–36 条是紧接着那一段踩的，在 `新对话交接-第二十一轮-官网收口与画布微调-20260919.md` §六。）

1. ⭐ **`.mov` 的容器品牌 `ftypqt`，Chrome 加载不出来**：`<video>` 一直 `readyState=0`、
   `canPlayType('video/quicktime')` 返回空，而**同一份文件在源站能播**（源站 CDN 有 referer 保护，
   我们的 curl 拿不到它的响应头做对比）。**改 nginx 的 content-type、去掉 nosniff 都没用** ——
   问题在容器品牌。正解是转标准 mp4（`ffmpeg -c copy`，不重编码）。
2. ⭐ **不能复用 `/downloads/` 那条 location 放媒体**：它 `default_type application/octet-stream`
   + `nosniff`，`<img>`/`<video>` 直接被拒收（而 200 是好的、看着像"图片坏了"）。
3. **导入的图片有一批是"没有扩展名"的图床链接**（`space.coze.cn/api/coze_space/gen_image?...`）：
   只看扩展名判断"是不是图片"会漏 → 改成**先看类型、再看扩展名**。
4. **源站会返回 200 + 0 字节**（797 个文件里有 1 个）：下载器要**把空响应当失败**，
   否则会留下一个 0 字节文件 —— 广场上就是一张裂图，而脚本还以为"下过了"。
5. **公开接口的 limit 之前卡在 60**，两处（`works` / `vibecoding-works`）——改一处漏一处的典型。
6. **`vibecoding_submissions` 与 `works` 是两套字段**（前者没有 `unpublished_at`）：
   "把某件作品下架"先看它在哪张表。
7. **守卫的 fixture 要够量**：翻页这条**必须 >12 件**才测得出来；我一开始只造了 2 件，
   分页断言等于没测。
8. **判分类要用 `data-category` 而不是 `data-type`**：卡片的 `data-type` 是**类型角标**
   （图片/视频/网页…），`data-category` 才是**分类**（画布作品/VibeCoding作品）——两者不是一回事。
9. **点站内作品会跳详情页**：守卫里"点开看查看层"必须点**导入件**（站内作品是 `<Link>`），
   否则页面一跳，后面的断言全找不到元素。
10. **`margin-left:auto` 的 computed 值不是 `"auto"`**（flex 项上会被解算成 px）：
    守卫要判"机构名贴不贴右边"，得比**右边缘距离**，不是比字符串。
11. **本机出网受限是常态**：`iicili.cyou` 本机 curl 不通、`npm registry` 不通、GitHub release 资产不通。
    离线办法：能通的那个方向借服务器（`ssh … curl`）；出包用本地 Electron 镜像（客户端仓库有脚本）。
