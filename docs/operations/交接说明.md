## 四、关键设计约定（必须遵守）

```text
1. 学生功能在 apps/website，没有独立 apps/student（已删除，不恢复）
   学生登录 → 回 / → 右上角头像 → 进入学习/我的作品/我的积分/我的课程/学习统计
2. 课堂画布是"受控"的：学生不能右键建节点
   节点来源 = 左侧素材面板的「生成框体」(按课时 generationSlots 数量) + 「本节课画布素材」
3. 框体 = 画布节点；课时 classroomConfig.generationSlots 定义数量/比例/尺寸/时长/模型
4. 提示词素材：学生点击 → 可视化选择插入哪个框体（不是序号）
   图片/视频/音频素材：点击直接加入画布
5. 教学素材 = 教师备课资料（分组+文件，PPT/Word/Excel/PDF/视频），学生不可见
6. 课堂类型 delivery_mode：课包级默认（course_series.delivery_mode），课时继承、可单独改
   VibeCoding 已预留但运行时未实现（发布会被拦）
7. AI 渠道：一个渠道可配多个模型（channel.models）；课时可从对应模态渠道的模型下拉单选
   生成时课时选的模型优先于渠道默认模型
```
