## 二、人眼可读版

**标题**：机构合作手册

**导语**：把「一门 AI 课」变成能复制的校区产品：课程、账号、授权次数与作品沉淀在同一套平台里。

### 1. 政策窗口：AI 通识课正从试点走向普及

国家和教育部门连续推动中小学人工智能教育：课程要能开齐开足，生成式 AI 要「可用、可管」。机构开班如果只靠零散对话工具拼起来，很难同时满足「能进课表、能管住账号与用量、每节课有作品」这三件事。

- 开课要能落地：标准课包 + 互动课件直接进课堂
- 用量要能管住：机构账号分级 + 授权次数按班分配
- 成果要能看见：作品沉淀进展厅，续费与招新都有素材

### 2. 别再「东拼西凑」做 AI 课

常见的做法是：对话用一家、写代码换一个编辑器、课件散在网盘和群聊里。老师每换一门课，就要重新教学生「今天用哪个网站」；机构真正头疼的是账号分散、费用难追溯、成果难沉淀、口碑难复用。

- 第一节课就在折腾注册、充值、找回密码，作品一个没动
- 老师被挤成「技术运维」：要会写提示词、会记账单、会帮孩子找回账号
- 费用不可控：各买各的，月底不知道超在哪
- 成果留不住：作业散在群聊里，招新没有统一案例库

### 3. 为什么不是「再找个对话平台」

机构评估 AI 课时，真正的对比对象不是某一门编程语言，而是「用通用 AIGC 工具自己拼一套」。差别不在模型强弱，而在课堂能不能长期交付——见下表。

### 4. 面向 8–16 岁的 AI 创作平台

学生用中文与 AI 伙伴「阿飞」对话，就能做出能运行的游戏、动画、互动故事与硬件作品。平台提供能力与课包，机构负责招生与教学。

- 中文对话创作，代码可见、当堂可玩
- 分屏预览：网页 / 图片 / 代码运行结果与对话同步
- 图片、视频、音乐同一入口生成，不用在多个 AIGC 平台之间切换
- 开源硬件：Arduino Uno 一键烧录，micro:bit 支持 MicroPython 上传与串口监视

### 5. 开课、管授权次数、沉作品

机构账号分级（管理员 / 教师 / 学员），学员无需自备 API Key；课包按班开通授权次数，用量有记录；作品沉淀进展厅，形成校区案例库。

- 机构账号：账号分级，避免密钥泄露与账号失控
- 授权次数：按班分配，剩余不足有提示
- 课程中心：标准化课包与互动课件，老师备课更省力
- 管理后台：账号开通、课包浏览、作品发布、用量记录
- 作品展厅：机构内作品聚合展示与在线预览

### 6. 正式开班四步

从开通到出作品，一条可复制的路径。

- 开通机构：配置席位与课包权限
- 创建学员账号：学生用机构账号登录即可创作
- 按课包授课：从课程中心进入课时，结合阿飞完成当堂作品
- 作品进展厅：形成校区案例库与招生素材

### 7. 体验课到正班：四步转化

先用一节体验课让家长看见「孩子做出来了什么」，再自然转进正班。

- 90 分钟体验：完成一个可玩 / 可点的小作品
- 当堂分享预览：家长当场看得见
- 作品进展厅：沉淀为口碑与招生素材
- 转入正班：同一账号与课包续学，不换平台

### 8. 旗舰课包：看得见的课程质量

不是网盘里的散页 PPT。互动课件进课程中心，翻页、进度、道具一体呈现——老师开课即用，学生也愿意跟着学。

- 课包与课时结构化：课时、课件与提示词一体交付
- 互动故事创作：从故事设定到分叉剧情、画风、配乐，完成一部能点、能选、能分享的作品
- 课程大纲与课件示例可在联系我们时索取
