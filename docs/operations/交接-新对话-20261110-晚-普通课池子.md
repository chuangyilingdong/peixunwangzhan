## 3. 当前模型（重要）

### 3.1 普通课 = 一个池子

- 范围：`course_series.owner_type='PLATFORM' AND series_type='NORMAL' AND include_in_normal_pool<>0`
  （2026-11-10 晚确认后：S1/S2/S3 共 48 节；两门成人/商家课标记为 0，不计入）。
- 池子的**存储键** = 最早创建的普通课系列（生产里是 S1 `series_ee83eed5780a46489d2c`）。
- 平台 → 机构：S1 上一条 `course_assignments`（quota_total/quota_used）；
  S2/S3 等其它普通课系列各有一条 **0 次数**的访问授权（课程中心/建课堂用）。
- 机构 → 学生：S1 上一条 `student_course_grants`（granted_units/consumed_units）；
  学生这个余额可以上任意普通课系列里没上过的节。
- 核销：课堂结束且该学生有有效 AI 产出 → 从 S1 的池子许可扣 1 次；
  核销明细 `student_course_grant_consumptions.series_id/lesson_id` 记录**实际**上的是哪一节。
- 「上过的课不能重复上」：按 `lesson_id`，跨 S1/S2/S3 同样生效。
- 体验课：不动。仍按自己的 `series_id` 建许可、1 节课、可反复上、机构不可回收、平台撤销。

### 3.2 平台/机构界面

- 平台「机构课包与授权次数」：普通课只出一行「普通课（N 节）」+ 体验课分行；
  「开通课包 / 调整授权次数」对普通课都传 `seriesId='NORMAL'`（服务端解析到池子）。
- 平台「授权与次数流水」：普通课一行；采购批次按 `scope_key='NORMAL'` 汇总。
- 机构「课包与次数 / 学生授权」：普通课一行 + 体验课分行；「授权次数」下拉只有 `NORMAL` + 体验课。
- 学生「已上课程」：仍显示具体 S1/S2/S3 的课时；余额是普通课总余额。
- 学生「我的课程」：有普通课许可时，**S1/S2/S3 各一张卡**（各自的 16 节），三张卡共用同一个余额；
  许可虽然只记在池子系列上，读取时会展开到池子里的全部系列（2026-11-10 补）。
- 机构端「学生授权详情」：普通课只展示池子那一行（历史 S2/S3 旧许可不再逐条显示）。

### 3.3 财务范围（3A）

- `license_purchase_batches` / `license_revenue_events` / `course_quota_changes` 新增
  `scope_type` / `scope_key`：普通课 `NORMAL/NORMAL`，体验课 `SERIES/系列id`。
- 普通课采购历史按 `scope_key='NORMAL'` 汇总（含历史 S2/S3 批次）。
- 报表按 scope 汇总即可把普通课合成一条。

### 6.1 已实现（本次改动）

- `course_series` 新增 **`include_in_normal_pool`**（默认 1；体验课恒 0）：
  - 1 = 计入普通课：算节数、进池子、共用一份次数；
  - 0 = 独立课程：不占 48 节、不进池子，授权/核销落在**自己的系列**上。
- 平台「新建课包 / 课包资料」表单新增复选框 **「计入普通课节数（S1/S2/S3 共一个次数池子）」**，

  独立课程在平台「授权与次数流水」和机构「课包与次数」里**单独一行**，可单独授权。
- 切换保护：课包上还有授权次数或有效学生许可时，不允许切换「计入普通课」
  （`NORMAL_POOL_IN_USE`）；把新的系列计入池子时会自动给已有池子授权的机构补 0 次数访问授权，
