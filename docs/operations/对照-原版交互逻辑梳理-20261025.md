# 原版交互逻辑对照梳理 · 2026-10-25

> 依据：原版前端明文源码 `E:\XiaoLingDang\_internal\strategist\static\`（app.js 4510 行 + 20 余个特性 JS）逐行走读。
> 结论先行：**此前五轮对齐的是「功能点清单」，不是「交互逻辑」。原版的心智模型是「一切工作流都长在对话消息流里的状态机卡片」，我们做成了「表单弹窗 + 独立面板」，所以用户感觉完全是两个产品。**

## 横切差异（影响所有功能，最优先）

| X1 | 所有工作流（创作/爆款/热点）的卡片**渲染在聊天消息流内**，与对话消息混排 | 工作流卡片在消息区上方独立一块 | 呈现逻辑 |

## 一、爆款复刻（用户截图指出的差距）

**原版（viral_recreation.js，509 行）**：
- 4 来源卡片：①同行爆款：同行观察→选同行→作品卡片墙（缩略图/赞/评/藏/时长/「已有本地视频可复用」）②爆款链接：粘贴分享文字 ③上传视频：本地 ≤200MB（role=同行参考，**不入素材库**）④现有文案
- 5 阶段：选来源 → extracting（提取原文）→ transcript_review（**可编辑确认原文**+复制原文）→ rewriting（流式 3 版）→ ready（3 版本 + **复刻蓝图**：开头机制/信息推进/转折/收束 + 换一批）
- 服务端状态机：`viral-recreations`（source_type peer/link/upload/text；confirm-transcript/regenerate/select 带 version 乐观锁）

**我们**：2 来源（粘贴文案/转写档案）；阶段：确认原文 → **选改造强度 → 选表达风格**（这两步原版没有，原版是自动拆蓝图结合账号资料）→ 3 版本（非流式）→ 存文案草稿。

**要改**：补 4 来源（同行作品选择器/链接解析/本地视频上传一次性使用）；去掉强度+风格两步、服务端自动按账号资料改写并产出 blueprint；加双击改稿、流式预览、聊天内嵌、复制原文按钮。

## 二、小铃铛对话（app.js renderChat）

**原版**：
- 附件系统：粘贴/拖入/选择图片视频音频 → `@图片1 @视频1 @音频1` 引用（9图/3视频/3音频上限），附件入素材库「其他」
- 模型双档切换（标准/快速）
- 创作会话嵌在消息流：work_log 步骤日志、idea→文案大脑选择→content_plan→copy→done、暂停/继续/精修(refine)/换一批/换同行参考/无同行
- 意图识别：输入"开始今天的选题/帮我想个文案…"自动进创作流
- 今日选题入口弹窗：「我有大致想法（写一句）」/「我没头绪」→推荐 3 个

**我们**：纯文本对话；无附件/@/档位/意图识别/暂停续写；选题弹窗只有方向输入。

## 三、同行观察（原版是「研究管线」，不是记录列表）

**原版**：同行卡片=管线状态机（粉丝/作品数 + 已下载/已分析/研究样本 三计数 + 下一步建议 + 研究报告徽章）→ 同行详情（作品网格、逐条下载/分析/重试）→ **研究报告**（生成后 `reference_ready` 才可用于今日选题）；批量下载带**筛选条件**（目标条数/最低赞/评/藏/转）；「更新全部同行」+自动同步设置。

**我们**：手动记录 + 简易采集面板（读主页/下载单条转写）。无计数、无管线、无报告、无筛选队列、无自动同步。

## 四、文案大脑（原版独立页签，我们完全没有）

**原版**：添加=粘贴创作者主页分享 → 设下载条件（目标 20 条/最低赞评藏转）→ 队列下载 → 逐条口播分析 → **「蒸馏大脑」**生成方法档案（brain_profile：思考框架/选题思路 + 创作者明确讲授的方法/作品里反复出现的写作习惯/可复用的综合规则，**每条带时间码证据引用**）→ 「设为常用」→ 创作流 brain_selection 阶段调用（"借用结构、节奏和表达方法，不模仿原作者身份"）。报告有 stale 概念（新增作品后可重蒸馏）。

**我们**：无。只有手动长期记忆。

## 五、素材库

**原版**：树形文件夹（含特殊文件夹 成片/、成片/已发布）、手机壳样式缩略图+海报帧、内嵌播放、另存为/移动/删除、**素材分析队列**（visual/audio 分析，关页继续跑）、筛选（未分类/待分析/失败/可复用源）、成片画廊（生成日期/发布日期）。

**我们**：扁平列表+文件夹 chip、上传/打开/删除。无移动、无分析、无成片、无树。

## 六、视频创作（原版是完整工作台，差距最大）

**原版**：video_workspace（项目行列表：生成/复刻/自动日更三模式）+ 视频制作对话（composer 带 电商带货/同城到店/品牌/剧情 四类型+细分+模型+时长+比例+钩子策略）、编导稿（director spec）可改、分镜复刻（storyboard_replication）、素材 @人物/@场景/@音色 角色引用、任务队列、voice_library 音色库、成片自动回素材库。

**我们**：脚本生成 + 单条文生视频。没有项目/编导稿/复刻底片/角色引用/任务队列。

## 七、数字人

**原版**：talking_head 是视频工作台的一种模式：@人物/@场景/@音色 三类素材、语速四档（自然/稍快/较快/极快+字/秒估算）、按字数估价（estimate 接口）、分段生成+失败重试（retry-segments）、「补充要求」弹窗（@ 引用）。

**我们**：单次提交面板。2026-10-25 修复底片 i2v 的顶层 images 与 identify-face 数组解析；克隆不可用时用参考音频直出，Kling session 仍过期时降级为底片+配音并明确标注「非精准对口型」。无角色引用/估价/分段。

## 八、内容计划/复盘（原版三个页签，我们无）

## 对齐优先级建议（按用户价值×可行性）

1. **P0 横切改造**：工作流卡片进消息流 + 乐观 UI + 流式预览 + 双击改稿（X1-X5）——这是「像不像原版」的体感核心

3. **P1 文案大脑页签**：蒸馏档案（时间码证据已有转写数据打底）+ 创作流大脑选择
4. **P1 对话增强**：附件+@引用、意图识别、双模型档位
5. **P2 同行观察管线化**：计数/下一步建议/筛选下载/研究报告
6. **P2 素材库**：树形文件夹+移动+成片画廊
7. **P3 设置页签**：原版用户自助配 Key；我们仍由平台后台统一管理。视频工作台（七/十五期）、内容计划（八期 + 十六期方案卡）、数据复盘（九/十四期）已补。
