# 内容工作台客户端 0.5.0 · 视频制作模式 · 2026-10-27

## 一句话

“做内容”的定稿阶段现在可以选择 `分镜成片 / 口播成片 / 一键托管`，并支持上传形象照、音色参考和复刻视频。一级入口仍为 5 个。

## 本轮完成

### 1. 三种制作方式

#### 分镜成片

沿用 0.4.0 流程：

```text
内容方案
→ 编导稿
→ 逐镜检查/修改
→ 确认渲染
→ 发布包
→ 发布复盘
```

#### 口播成片

```text
口播稿
→ 选形象照
→ 选/上传音色
→ 选四档语速
→ 创建口播任务
→ 保存/确认口播稿与分段
→ 数字人合成
→ 发布包
```

已接：

- `POST /video/works`，`productionMode=talking_head`；
- `PUT /video/works/:id` 保存口播稿；
- `confirm` 确认数字人合成；
- 已有轮询、成片和发布包链路复用。

#### 一键托管

```text
只写主题
→ 选形象照/音色/语速
→ 免费写口播稿和分段
→ 停在确认页
→ 用户确认后才合成
```

已接：

- `autoHost=true`；
- planning → draft 轮询；
- 确认前不创建付费合成任务。

### 2. 素材上传

新增主进程 IPC：

```text
junshi:app-upload-asset
```

用途：

- 上传形象照；
- 上传 2–15 秒音色参考音频；
- 上传爆款复刻参考视频；
- 走系统文件选择器与平台 `/assets` multipart 接口；
- 文件不经过 renderer 的内存桥，renderer 不持有 token。

### 3. 音色准备

- 上传音频后调用 `POST /voices`；
- 轮询 `/voices` 直到 ready/failed；
- 只有 ready 音色才允许创建口播任务；
- 上游克隆不稳定时沿用已有的参考音频直出降级策略。

### 4. 爆款复刻来源

桌面端来源增至 4 个：

```text
现有文案
已转写档案
抖音单条作品链接
上传本地视频
```
