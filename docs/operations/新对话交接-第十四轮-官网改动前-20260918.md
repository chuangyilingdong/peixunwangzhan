## 三、不许破的口径（这几条是这一轮反复纠正出来的，最重要）

1. **命名：平台侧没有"算力额度"这个说法，只有"授权次数"** ——
   一律用 **总授权次数 / 已授权次数 / 剩余授权次数**；界面与文档不许再出现"算力额度""总人次"。
2. **算力额度一类的东西一律不拦人**（`enforced: false` 是机器可读承诺）：
   课堂成本预警、每学生算力观测上限、课包算力预估，全是**平台内部观测**口径；
   **学生端看不到任何额度**，也不会因额度被拒。唯一还按"量"拦的是**授权次数不足**（人次库存，不是算力）。
3. **内部成本口径不上公开面**：课程算力预估（`estimatedCreditsPerPerson`）与每学生预算
   （`perStudentBudgetFen`）都用**显式开关**（`normalizeSeries(..., { includeEstimatedCredits: true })`）
   只发给平台端读取面；上游账户余额探针只有平台端有（SUPER_ADMIN + ADMIN_BILLING 双门禁）。
   **验收里有一条反向断言**：官网包里不许出现 `预估消耗` / `灵动值/人` / `perStudentBudgetFen` /
   `estimatedCreditsPerPerson`。**动官网时这条最容易踩**。
4. **取消授权只有平台端有权限**：机构端没有入口、也不展示"取消资格"那一层；`p55` 的 404 断言**不动**。
5. **上游账户余额只有平台端能看**（机构端看的是自己的消耗，口径是"对外售价"，不是我们的成本）。

## 四、接下来做官网：这块现在长什么样

- **应用**：`apps/website`（Vite）。nginx 把 `/` 指到它；`/admin/`、`/org/`、`/student/` 是另外三个应用。
  学生功能已并入官网（`/login` → `/learn` → 课时 → 进课堂画布），**没有独立的 `/student/` 后台**。
- **构建**：`deploy/production/build-production.sh` 一次构建三个前端（admin / org / website），
  产物拷进 `releases/<stamp>/apps/<app>/`。**别单独构建某一个再手工拷**，会绕过 BUILD-METADATA 自检。
- **内容管理**：官网的文案大部分走 **CMS** —— 平台端「官网内容」页（`apps/admin` 的 `WebsiteContent`）
  写 `website_content` 相关接口；官网用 `useWebsiteContent(...)` 读，**有 fallback 常量**
  （比如 `apps/website/src/main.jsx` 的 `CMS_FALLBACK`）。改文案优先改 CMS 里的，别硬编码。
- **公开接口**：`apps/server/src/routes/communication/public.js`（`/api/public/*`）——
  课包列表/详情/作品展厅等；这一层**必须继续不带内部成本字段**（见口径 3）。
- **已知的官网文案待办**：官网多处仍写 **"灵动值"**（营销口径的历史词），
  例如首页/机构方案/选型对比/产品手册。**平台侧已经统一成"授权次数"了**，官网要不要跟着改口径，
  由你定；若要改，注意它是**营销文案**，和平台侧的"授权次数"未必是一回事，别机械替换。
- **动官网时最容易踩的三件事**：
  ① **别把内部成本口径带出去**（口径 3，验收有反向断言）；
  ② **别用 `vite preview` 本地跑通就以为没事** —— 这一轮撞过两次"只有生产才犯"的问题
     （`.mjs` 被 nginx 当 octet-stream + nosniff → 浏览器拒收模块脚本；`blob:` 被 CSP `connect-src 'self'` 拦）。
     验收必须包含"部署后对真实站点取响应头 / 真浏览器"；
  ③ 生产 build 带了 `VITE_PUBLIC_SITE_URL` 等环境变量，**产物 hash 与本机构建天然不同**，
     别拿 hash 对不上当发布失败的证据。
