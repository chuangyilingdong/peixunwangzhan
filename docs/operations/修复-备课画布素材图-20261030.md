# 修复 · 老师端备课画布素材图失效（2026-10-30）

## 现象

老师端从机构后台「课程备课」进入画布课堂，点「素材1」后画布上的图片裂图；学生端从同一节课进入、点同一素材正常。

现场课时：`lesson_b57bde987c9c4b4a95e9`（不同损伤类型的老照片素材）  
素材：`material_4a6e4dd8b97149278c9a`（素材1）  
文件：`file_d22c2283b2d742e6969d`（1.jpg）

## 根因

课时画布素材上传时存的是**学生域地址**：

```text
/api/student/file-assets/file_d22c2283b2d742e6969d/download
```

- 学生域路由 `handleStudentFileAssets` 第一行就是 `requireRole(ctx, ['STUDENT'])`；
- 备课画布用的是**机构端 token**（`CanvasPrep` 读 `readAppSession('org')`），取同一个地址 → 403；
- 学生端自己带 STUDENT 身份取 → 正常。

文件本身没有问题：`file_assets` 里是 `MEDIA_ASSET / PUBLIC_PLATFORM / ACTIVE / NOT_REQUIRED`，
平台/机构/学生登录后都应有读权限，缺的只是「用对角色对应的路由」。

## 修复

`apps/website/src/pages/CanvasPrep.jsx`：备课页加载数据时，把 `canvasSnapshot`、
`materialGroups`、`generationBoxes` 里的学生域素材地址**递归改写**为机构域：

```text
/api/student/file-assets/<id>/download
  → /api/org/file-assets/<id>/download
```

- 只改读取时的内存数据，**不改数据库里的 asset_url**；学生端与作品公开页的 student 域代理逻辑不受影响；
- 平台后台 `MaterialPreview` 早就有同款「student/org → admin」读取时改写，本次沿用同一口径；
- 本地草稿里上次保存的节点地址也会被改写，老师不用清草稿。

提交：`d4570f2f fix(prep): 备课画布素材图按机构角色改写地址`

## 发布与验证

- release：`20261030T021224Z`（源码 `d4570f2f`），39/39 自检通过，health 200；
- 生产 mock 验证：用线上 `/learn/prep/test-lesson` 页面 + 拦截备课接口，画布只请求
  `/api/org/file-assets/file_test/download`，不再请求学生域；图片以 blob 正常加载；
- 真实文件核对：`file_d22c2283b2d742e6969d` 等 4 张素材均为 `PUBLIC_PLATFORM / ACTIVE`，
  机构端路由可读；
- 学生端未改，无需回归。

## 注意

- 不要为了临时绕过而把数据库里的课时素材地址手动改成 `/api/org/...`：
  老师端能看，但学生提交作品后公开作品页的图片代理只认 student 域，容易出现新的裂图；
- 以后新增课时素材仍按原逻辑存 student 域，备课页的读取改写会兜住。
