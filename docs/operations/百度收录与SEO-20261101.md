## 五、仍未解决的两个大问题

### 1. `ecs.misoos.com` 还在复制官网

- DNS 指向 8.138.150.19（与 aicyld.com 同一台）；
- nginx 未按 Host 区分，默认站点返回同一套官网；
- 它的 HTTPS 证书是 aicyld.com 的，浏览器会报证书错误；
- 页面 canonical 虽指向 aicyld.com，但百度仍可能保留这个旧域名的结果；
- 目前**没有**做 Host 级 301/noindex，也**没有**删 DNS。

建议：

- nginx 给 `ecs.misoos.com` 加 80 端口 301 到 `https://aicyld.com`，并加默认站点拒绝未知 Host；
- 或让 `misoos.com` 持有者删除该 DNS；
- 安全优先，可对该 Host 返回 noindex/410。

### 2. 站内还没有「创弈灵动」

- 全站品牌是「灵动ai学院」，源码/页面没有「创弈灵动」；
- 百度搜「创弈灵动」不会关联到本站；
- 需要确认公司全称/品牌关系，再把「创弈灵动（灵动ai学院）」写进：
  title、description、H1、页脚、About、协议主体、JSON-LD `Organization`。
