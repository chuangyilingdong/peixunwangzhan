```json
{
  "source": "showcase",
  "sourceId": "<slug>",
  "workType": "webpage | miniGame",
  "coverUrl": "https://aicyld.com/media/web-works/<slug>/cover.jpg",
  "entryUrl": "https://aicyld.com/media/web-works/<slug>/index.html",
  "contentUrls": [],
  "externalUrl": null,
  "authorName": "官方课堂"

```

`works` 行：`status=PUBLISHED`、`is_public=1`、`share_token='scw-<slug>'`、`copyright_confirmed_at` 非空。

## 浏览与分享（本轮改动）

- 广场卡片现在对 `entryUrl` 作品是**真正的 `<Link>`**：点开进 `/works/<分享码>`，右键/新标签也能用；原来的整屏查看层只作为「拿不到分享码」时的兜底。
- 作品页是**整屏独立层**：52px 顶栏（手机 46px，含类型、标题、作者/机构/日期、复制链接、返回广场）+ iframe 吃满剩余高度；不套官网导航/页脚，打开就是作品本身。
- 地址栏就是分享链接；浏览器标签显示**作品名**；右上角「复制链接」一键复制。1600×1000 下作品区 1600×948，390×844 下 390×798。
- 沙箱保持 `sandbox="allow-scripts allow-modals allow-forms allow-popups allow-downloads"`，**没有 `allow-same-origin`**：作品读不到主站 cookie/localStorage（独立页是主站同源的 fixed 层，这层沙箱仍然是安全边界）。
- 因此给两个依赖 localStorage 的作品加了内存兜底：文字冒险的结局收集、班级主页的留言在本次打开期间仍然有效（关闭页面后不保留）。
- 原有的 9 件 aimagc 导入网页作品也自动获得同样的独立作品页（它们的 token 是 `ww…`）；图片/视频类导入件仍走原来的查看层。

## 顺带修正

- 广场前端合并 VibeCoding 与画布/导入件时，原来只按 `featured` 排序，非精选项保持拼接顺序（VibeCoding 全在前、导入件全在后），新作品会被压到第 5 页。现在改为「精选优先，其余按 `submittedAt` 倒序」。
- 后台「彻底删除」现在也认得 `source=showcase`，会把 `web-works/<slug>` 挪进 `_trash/`。
