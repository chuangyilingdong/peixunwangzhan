## 数据形状

沿用导入件那套 `works.canvas_snapshot.imported`：

```json
{
  "source": "showcase",
  "sourceId": "<slug>",
  "workType": "webpage | miniGame",
  "coverUrl": "https://aicyld.com/media/web-works/<slug>/cover.jpg",
  "entryUrl": "https://aicyld.com/media/web-works/<slug>/index.html",
  "contentUrls": [],
  "externalUrl": null,
  "authorName": "官方课堂"
}
```

`works` 行：`status=PUBLISHED`、`is_public=1`、`share_token='scw-<slug>'`、`copyright_confirmed_at` 非空。
幂等写入脚本：`scripts/import-showcase-webworks.mjs`（`--dry-run` 只检查媒体，不加则写库）。

## 浏览体验（本轮改动）

- `/works` 里 `entryUrl` 作品：查看层铺满整个浏览器，标题栏只有 43px，iframe 用**真实视口**排版（1600×1000 下是 1600×957），不再缩放、不再有内外两层滚动条。
- 长页面（旅行、班级主页、博物馆）仍按页面自身设计滚动 —— 与直接双击打开 HTML 一致；单屏应用（英语私教、猜数字、文字冒险）正好一屏。
- 沙箱保持 `sandbox="allow-scripts allow-modals allow-forms allow-popups allow-downloads"`，**没有 `allow-same-origin`**：作品读不到主站 cookie/localStorage。
- 因此给两个依赖 localStorage 的作品加了内存兜底：文字冒险的结局收集、班级主页的留言在本次打开期间仍然有效（关闭页面后不保留）。

## 顺带修正

- 广场前端合并 VibeCoding 与画布/导入件时，原来只按 `featured` 排序，非精选项保持拼接顺序（VibeCoding 全在前、导入件全在后），新作品会被压到第 5 页。现在改为「精选优先，其余按 `submittedAt` 倒序」。
- 后台「彻底删除」现在也认得 `source=showcase`，会把 `web-works/<slug>` 挪进 `_trash/`。
