## 三、方案与顺序（**别一次把三样都换掉**）

```text
第 0 步  新机"原样搬家"：同样的目录布局 + systemd + nginx + certbot，数据库**继续用 SQLite**
         （放本机盘；先别碰 RDS）→ 从旧机备份恢复 → 用 hosts/直连 IP 验完 → 切域名解析 → 观察
第 1 步  OSS：把上传/媒体读写改成 OSS（私有 bucket + 签名 URL，学生私有素材不能有公网地址）
第 2 步  RDS：**单独立项**。这是换数据库引擎（schema / 所有 SQL / JSON 函数 / 迁移脚本 / 几十条守卫），
         不是搬家。先在新机上把 SQLite 跑稳，再谈它。
```

**为什么这样排**：搬家当天要能回滚（DNS 改回来 + 旧机还在）；RDS/OSS 混进来，出问题时你分不清是哪一层的锅。
