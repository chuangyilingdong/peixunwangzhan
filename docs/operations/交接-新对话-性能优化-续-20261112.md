## 1. 11/12 本轮做了什么

### 1.1 控制面缓存（commit `88ac22a0`）

- auth `users/organizations` 5 秒 TTL（sessions 仍每请求实时查，登出/踢下线即时）；
- 生成轮询 `succeeded/failed/costFen` + provider 信息 30 秒缓存；
- 所有 users/organizations 写入点显式失效。

### 1.2 Dashboard N+1 + 冷读索引（`020e3472` / `0dd7c903`）

- 已发布快照齐全时跳过实时能力/素材/框体查询；
- 每请求只读一次 `ai_provider_policy`；课时数/授权行由主查询带出；参与记录一次查询；
- 课程详情不再重建整份 `buildStudentContext`；
- 可访问课程一次批量取课时；项目列表快照齐全 0 查询；
- 迁移 57：`generation_jobs(user_id,org_id,status)`、`compute_attempts(org_id,user_id(64),status(16),sale_price_fen)`。

### 1.3 nginx（commit `77818c3d`，线上已 reload）

- HTTP/2、upstream keepalive（`keepalive 32` / `keepalive_timeout 2s`）；
- `/api/` `proxy_request_buffering off`；
- TLS session cache；
- 线上配置与仓库有漂移（旧安装包 404、`/test-api/`、junshi include），采用定点修改，未整文件覆盖。

### 1.4 submit-upload（`7334f006` / `5232f6c9` / `a7d91df0`）

- base64 只解一次、解码后释放字符串、`timings.jsonBytes` 改 content-length；
- 兼容 multipart 入口（`meta` + `file:<i>` + `cover`），修复过“文本 part 未转字符串导致正文空”的 bug；
- 画布轮询：页面隐藏暂停、详情 2s→3s→5s 退避；网关 `/api/gateway/*` 跳过 `resolveAuth`。

### 1.5 运行时指标 + 压测工具（`8532a5c1`）

- `GET /__metrics`（仅 loopback、拒绝 `x-forwarded-for`）：路由 P95、DB 池等待、SSE 活跃、归档队列、RSS/load、网卡速率；
