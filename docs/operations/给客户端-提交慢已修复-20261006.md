## 接口变化（加法，不破坏契约）

`POST /api/student/runtime/submit-upload` 的成功响应**多了一个 `timings` 字段**：

```json
"timings": {
  "fileCount": 3,
  "contentBytes": 21700000,   // 二进制素材解码后的总字节
  "jsonBytes": 29000000,      // 这次请求体（含 base64）的大小
  "scanMs": 0,                // 扫描耗时（现在恒为 0：SCANNER_DISABLED）
  "storageMs": 210,           // 落盘/入库文件资产
  "dbMs": 45,                 // 作品行/产物清单写库
  "totalMs": 320,             // 服务端整单处理
  "scanStatus": "SCANNER_DISABLED",
  "scanCached": 0
}
```

**建议客户端顺手做一件事**（可选，但很有用）：把 `timings` 打进客户端日志。
以后客户端再报"提交慢"，直接把这一段回传给我们，比去翻服务端日志快得多。

## 需要你们知道的安全边界（免得误会成"漏配"）

关掉的只是**内容扫描（clamscan）**。仍然保留：扩展名 + MIME 白名单、**魔术字节嗅探**、
单文件大小上限、读 body 之前的**内存闸**（在飞/并发限制）、svg 一律 `attachment`、下载口鉴权。

**恢复方式**（如果哪天政策变了）：生产 `/etc/ai-kids-platform/production.env` 里
`FILE_UPLOAD_SCANNER=off` 改回 `FILE_UPLOAD_SCANNER=/usr/local/bin/clamscan-limited`
（或换成 clamd 的 `clamdscan`）再 `systemctl restart learning-platform-production` 即可 —— 一行的事。
本地/预发可以用同一开关试；`FILE_UPLOAD_SCANNER_ARGS` 可以给扫描器传自定义参数（默认 `--no-summary`）。
