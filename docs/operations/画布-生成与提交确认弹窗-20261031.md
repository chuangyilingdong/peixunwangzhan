# 画布 · 生成与提交改为内部确认弹窗（2026-10-31）

## 需求

- 学生端画布**点生成按钮**时，多一步确认，文案：
  `确认内容无误，点击生成。`
- 「提交作品」目前是浏览器原生 `window.confirm`，改成**画布内部弹窗**；
  生成确认也用同一套内部弹窗。

可行性：可行。两处都只是前端 UI，不涉及生成/提交接口；画布已有 `.cv-dialog`
浮层样式（课堂素材插入框体用的就是它），复用即可。

## 实现

### 1. 生成前确认

- `packages/canvas/src/index.jsx`
  - `CanvasSurface` 增加可选 `beforeGenerate`；
  - `generateNode()` **先** `await beforeGenerate(...)`，只有返回 `true` 才把节点置为
    `generationStatus: 'PENDING'` 并发请求；
  - 取消时直接 return —— 不闪「生成中」、不产生失败状态、不发 `/ai/generations/async`。
- `packages/shared/src/canvasWorkspace.jsx`
  - 新增通用 `askConfirm()` / `settleConfirm()`（Promise 由弹窗按钮 resolve）；
  - `confirmGenerate()` 文案：标题「生成前确认」，正文 `确认内容无误，点击生成。`，
    按钮「取消 / 确认生成」；
  - 传给 `CanvasEditor`：`beforeGenerate={prepMode ? undefined : confirmGenerate}`；
  - 侧栏生成表单 `generateMaterial()` 也先走同一个确认。

### 2. 提交作品

- `submitWork()` 里的 `window.confirm(...)` 删除，改为：
  - 标题「提交作品」；
  - 正文保留原授权确认：「提交给老师前请确认：这是你自己的作品，并同意平台在作品广场展示。」；
  - 按钮「取消 / 确认提交」；
  - 取消 → 不请求、不置 `busy`；确认 → 走原来的提交路径。

### 3. 弹窗

- 复用 `.cv-dialog` / `.cv-dialog__panel`；
- 新增 `.cv-dialog__body` / `.cv-dialog__actions`（styles.css）；
- 点遮罩或按 Esc = 取消；面板内点击不关闭；取消按钮 `autoFocus`；
- 生成/提交共用同一个 `confirmDialog` 状态，避免两套弹窗样式漂移。

## 验证

- `scripts/p176-canvas-classroom-browser.mjs` 增加两段真 Chrome 检查（用真实画布项目夹具）：
  - ④ 有产出的项目点「提交作品」→ 出现 `.cv-dialog__body`，文案含「提交给老师前请确认」，
    **没有触发浏览器原生 dialog**；
  - ⑤ 生图节点点「生成画面」→ 出现 `.cv-dialog__body`，文案含
    `确认内容无误，点击生成。`；**取消前/取消后都没有 `/ai/generations/async` 请求**。
- 三端构建通过；生产产物里能搜到两段文案，website 包 `window.confirm` 出现次数 **0**。
