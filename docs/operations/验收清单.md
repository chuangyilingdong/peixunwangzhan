# 验收清单（当前基线）

> 状态：当前有效
> 更新日期：2026-09-11
> 用于每次发布前的人工验收；以真实浏览器 + 真实接口结果为准，不以静态代码通过为准。
> ⚠️ 2026-09-11：机构端已按用户要求删除 7 个功能（课堂任务、进入学习上课、积分流水、积分账务、
>   作品数据中心、积分套餐、账号申请），机构端导航只剩 11 条；本清单已同步（见第二节）。

## 一、管理端 `/admin`（SUPER_ADMIN）

- [ ] 登录后进入 `/dashboard`
- [ ] 机构管理 → 机构详情 → “充值”按钮可打开充值弹窗
- [ ] 充值成功后机构账户余额增加，充值历史出现记录
- [ ] 计费页“积分账户管理”可查看机构账户
- [ ] 充值历史列表分页正常

## 二、机构端 `/org`（ORG_ADMIN / TEACHER）

- [ ] 登录后进入 `/dashboard`；左侧导航 11 条，且**不含**课堂任务/进入学习上课/积分流水/积分账务/
      作品数据中心/积分套餐/账号申请
- [ ] 直接访问已删路由（`/org/tasks`、`/org/recharge`、`/org/packages` 等）回落到机构总览
- [ ] “班级与课堂”能开课、结束课堂
- [ ] “成员管理”能建号、停用、调班
- [ ] “配额管理”加载成员列表（学生/教师角色切换）
- [ ] 单用户“调整”配额弹窗可提交
- [ ] 批量分配配额可提交
- [ ] 配额历史弹窗可查看
- [ ] “积分用量”加载余额与用量（按天数切换）
- [ ] “学员开通”能读到套餐并创建开通单（⚠️ 套餐页面已删除，只能用已有套餐）
- [ ] “作品管理”能看到作品、处理举报、设机构精选
- [ ] “问题反馈”能处理学生反馈

## 三、官网（学生）

- [ ] 学生登录后回到 `/`（不跳 `/learn`）
- [ ] 首页右上角头像可展开下拉菜单
- [ ] 菜单包含：进入学习 / 我的作品 / 我的积分 / 我的课程 / 学习统计
- [ ] 我的积分页显示汇总 + 使用记录 + 配额变更历史
- [ ] 进入学习 → 课程/课时 → 画布课堂可进入
- [ ] 公开页：作品广场、课程广场、课程详情、下载、预约表单均正常

## 四、服务健康

- [ ] 生产 `/health` 与公网 `/api/health` 返回 `status: ok`
- [ ] `systemctl status learning-platform-production` active/enabled、`NRestarts=0`
- [ ] 生产软链指向最新 release：`readlink -f /srv/ai-kids-platform/production/current`
- [ ] 内测服务已下线（`systemctl is-active learning-platform-internal-test` 应为 not-found）
- [ ] 公网 `/`、`/admin/`、`/org/` 均 200（无 `/student/`）

## 五、回归关注点（重构后）

- [ ] 同步 `/api/ai/usage` 扣费：成功扣费、余额不足拦截、失败不扣费
- [ ] 异步生成结算：成功扣 1、失败/阻断不扣
- [ ] 跨机构查询被拦截（org_id 过滤）
- [ ] 配额调整后用户剩余 = 上限 - 已用
