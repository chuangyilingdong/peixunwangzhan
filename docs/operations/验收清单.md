# 验收清单（当前基线）

> 状态：当前有效　｜　更新日期：2026-09-13
> 每次发布前用它人工过一遍；**以真实浏览器 + 真实接口结果为准**，不以静态代码通过为准。
> 口径与产品背景见 `docs/README.md`。
>
> ⚠️ 2026-09-13 修订：原清单里的**积分/配额与班级**相关项全部作废（积分系统已删、班级已退场），
> 已换成算力池与课堂口径；`/student/` 入口也回来了（学生端由它指到 `apps/website`）。

## 一、管理端 `/admin`（SUPER_ADMIN）

- [ ] 登录后进入 `/dashboard`；指标卡能读出来（含「课堂场次（查询期）」）
- [ ] 机构管理 → 机构详情，能读；停用/启用机构可用
- [ ] 「模型与算力」五步能走通：渠道与模型、**每次调用单价**、算力网关（可选）、用量与账单、模态开关
- [ ] 单价改动后立即生效且**不追溯**（旧记录金额不变）
- [ ] 「平台作品」能看作品、举报处理、设精选/下架，且「未通过」与「已下架」分得清楚
- [ ] 「官网内容」能改文案并发布；「平台用户」能改角色（平台管理员角色不可改）

## 二、机构端 `/org`（ORG_ADMIN / TEACHER）

- [ ] 登录后进入 `/dashboard`；左侧导航与 `main.jsx` 的 `navigation` 一致
- [ ] 直接访问已删路由（`/org/classes`、`/org/tasks` 等）回落到机构总览
- [ ] **课堂**（`/classrooms`）：创建课堂（选课包 → 第几节课）→ 加学员（可加/不可加两栏，不可加给原因）
      → 名单为空时「开始上课」置灰 → 开始（确认弹窗）→ 学员进得去 → 结束（结算）/ 待上课可解散
- [ ] 「课堂」页「查看课件」在新标签打开那节课的教案抽屉
- [ ] 「成员管理」能建号、停用、重置密码；**没有**「调班/授权班级」（已随班级退场移除）
- [ ] 「学员许可」能把课包分给学员，扣次数；撤销由平台兜底
- [ ] 「课包概览」每个课包的可授权/已分配/剩余/学员/老师/课堂数正确，能下钻「分给了谁」
- [ ] 「算力用量」按天切换，能看消耗、能力分布、高频学员与每笔明细（上下文显示**课堂**名）
- [ ] 「作品管理」能看到作品、处理举报、设机构精选；筛选按**课堂**（不再是班级）
- [ ] 「问题反馈」能处理学生反馈

## 三、学生端（`/student/` → `apps/website`）

- [ ] 学生登录后回到 `/`（不跳 `/learn`）
- [ ] 首页右上角头像下拉：进入学习 / 我的作品 / 我的课程 / 学习统计（**没有**「我的积分」，已删）
- [ ] 「课程中心」课时卡的状态徽标与原因逐条对：未加入课堂 / 待上课 / 上课中 / 已完课 / 未完课 / 被移出课堂
- [ ] 已加入且已开始 → 按钮是「进入课堂」；**有草稿时是「继续创作」且复用同一个项目**（不新建）
- [ ] 未加入任何课堂 / 有许可但没排课 → 原因指向正确的人（「请让老师把你加进课堂」）
- [ ] 「我的课程」能看到未授权课包并标「未授权」；「我的作品」展示课堂名
- [ ] VibeCoding 课表徽标与画布一致（上课中/待上课/已完课/未完课/未加入课堂）
- [ ] 公开页：作品广场、课程广场、课程详情、预约表单均正常

## 五、回归关注点

- [ ] **进课三层门禁**：没许可 → `COURSE_GRANT_REQUIRED`；有许可没排进课堂 → `NOT_IN_CLASSROOM`；
      待上课 → 等老师开始；课堂结束 → 立刻失效
- [ ] **完课判定**：这节课消耗过算力 → 已完课；没花过钱 → 未完课（可以重新排进课堂再上）；
      已完课不能再排进同一节课
- [ ] **一个学生在一节课上只能属于一个未结束的课堂**（另一个课堂里他会进「不可加」并写明占用者）
- [ ] **算力池**：成功调用才记 `cost_fen`；失败/阻断不扣；改价不追溯
- [ ] **教师数据范围**：只看得到自己创建的课堂 / 自己课堂里的作品与用量（`scripts/p69` 钉着）
- [ ] 跨机构查询被拦截（`org_id` 过滤）
- [ ] 数据迁移后**零丢失**（发布前后逐表对行数；回填类改动先看 `scripts/p74`）
