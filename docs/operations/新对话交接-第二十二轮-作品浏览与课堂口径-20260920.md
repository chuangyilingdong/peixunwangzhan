## 二、这一轮做了什么（九件 + 客户端一条线）

### A. 广场查看层：改成"逻辑视口 + 等比缩放"（`ad961c3`）

用户报：广场点开贪吃蛇这类网页作品，小屏上要在框内往下滚 ——「这游戏我根本无法玩」。
**根因**：`.pl-frame` 写死 `height:62vh`，而学生页自带固定尺寸（实测贪吃蛇那页要 **600px 高**）。
**改法**：`PL_FRAME_MIN={w:640,h:768}` —— 内层页面按"不小于这个逻辑视口"渲染，再由 JS 等比缩放到可用空间
（`useLayoutEffect` + `ResizeObserver`，量不到就退回铺满）。逻辑视口高度**永远 ≥768** → 结构上不可能有滚动条。
另外矮屏（`max-height:780px`）压紧查看层自己的头尾，省下的高度全给作品；打开时锁住背后页面滚动。
实测：1280×720 框体 446→**583**（游戏完整装下、框内滚动条消失）；门槛从视口 919px 降到约 707px。

### B. 学生端删掉「学习统计」（`be30ae3`）

照**口径㉒**（删一整页要"一处不落"、路由留重定向）办：下拉项 / `<title>` 映射 / 页面文件（`MyStats.jsx` 删除）/
服务端那条指向它的旧注释；路由**留了重定向** `/my-stats → /learn`（老书签不 404）。

### C. 「我的作品」改成真能打开（`be30ae3`）

原来卡片只在**已上广场**时给「查看 →」，其余写"平台发布后可查看" —— 学生做完的东西自己看不到。

  `/sessions/:id/works/:source/:id`（老师看同一件作品）对齐；**只校验"是不是你自己的"，不看发布状态**。

### D. 修两个"只有线上跑才暴露"的 bug（`1e7439e`）

1. **图片读不出来**：照 org 端写法 `fetchBlobUrl()` 拿到 blob: 后又 `fetch(blobUrl)` 转 data:，
   而生产的 CSP 是 **`connect-src 'self'`**（blob: 只在 `img-src` 白名单里）→ 被拦成 "Failed to fetch"。
   → 共享 api 客户端新增 **`fetchDataUrl(path)`**：直接从 `/api/` 取字节转 data:，不绕 blob: 中转。
2. **「作品预览」标题重了两层**：`ReplayPreview` / `ReplayFilePreview` **自己就带**那层标题栏（内部是 ReplayPanel），
   外面又包了一个。→ 结构与公开作品页一致：真文件用 `ReplayFilePreview`、网页用裸 `ReplayPreview`。

## 三、不许破的口径（承接 1–24；**本文新增 25–36**）

25. ⭐ **查看层的网页作品必须"零滚动条"**：内层按「不小于 `PL_FRAME_MIN`（640×768）的逻辑视口」渲染、
    整体等比缩放到可用空间；**别再把框体写死成某个 vh**。有空间时缩放封顶 1（不放大）。
26. ⭐ **私有素材进 `<img>` / 沙箱预览必须转 `data:`**，且**用 `api.fetchDataUrl`**——
    生产 CSP 是 `connect-src 'self'`，blob: 只在 `img-src` 里：能当图片地址、**不能**再 `fetch()` 它。
27. **网页作品 iframe 的 sandbox 不许带 `allow-same-origin`**（延续口径⑧），也**不给"在新窗口打开"出口**。
    ⚠️ p120 读源码时钉的是两个字面量：`src={work.entryUrl}` 与它附近的 `sandbox="…"` —— 重构时别把它们挪走/改名。
28. **`ReplayPreview` / `ReplayFilePreview` 自带"作品预览"标题栏**，外面**不要再包一层 `ReplayPanel`**。
29. ⭐ **「我的作品」里每一件都必须能打开**：走学生口 `/api/student/works/:source/:id`，
    它**只校验"是不是你自己的"、不看发布状态**。别再回到"平台发布后可查看"那种死路口。
30. ⭐ **作品要按内容给"看的方式"**：网页（沙箱里直接玩）/ 图片（大图 + 缩略图，能一张张选）/ 文档 / 画布；
    **默认"能玩能看优先"**（网页 > 图片 > 文档 > 画布）——与公开作品页"主产物优先"**有意不同**。
31. **作品详情要写清「课包 › 课时」**（+ 老师）：预设提示词与次数上限都是**按课时**配的。
32. **`client-context` 必须说清"这次算哪节课"**：`classroom` 带课包/课时/老师；没有在上的课时给 `upcoming`，
    但**不发密钥**（"老师点了立即上课才能进"那道闸不动）。
33. **一个学生最多属于一个未终态课堂**（沿用口径）；**加人时拦**（`IN_OTHER_SESSION`），
    **开课时也复查占用**（本轮补，见 §二.G）。
34. ⭐ **界面上的预检必须与"真正那一步"同一口径**——不能更严（界面撒谎说不能做、其实能做），
    也不能更松。本轮那条"账号异常或已停用"就是这么来的。
35. **删整页 / 删整块要"一处不落"**：入口、路由（**留重定向**）、标题映射、组件、死样式、
    服务端注释、**以及守卫里钉着的那条断言**（本轮 p115 / p118 / p78 都跟着改过）。
36. **动生产数据（清理/删除）**：先备份（JSON 导出受影响行）→ `PRAGMA foreign_keys = ON` → 一个事务 →
    复查（应为 0）。⚠️ 外键是 `SET NULL` 的地方要主动处理（`class_sessions.lesson_id` 就是），
    否则会留下"没有课时的课堂"，把学生**永久占住**（占用判定不看课时）。

## 六、这一轮踩过的坑（承接 1–36；**本文新增 37–47**）

37. ⭐ **`max-height` 会静默吃掉你对 `height` 的改动**：查看层那次，`.pl-viewer-box` 上的 `max-height:92vh`
    才是真正卡住高度的那个（720 视口下 92vh=662，正好是"只改 height"时的实测值）——不解除就毫无效果。
38. ⭐ **blob: 在生产被 `connect-src 'self'` 拦**（`img-src` 里有 blob:，所以能当图片地址、**不能**再 `fetch`）。
    同一个 `fetchBlobUrl` 在 org 端是好的（CSP 不同），所以"这份代码在那边没问题"不能当证据。
39. **iframe 是刻意的 opaque origin**：既拿不到父页面的 `blob:`，外部也读不到它内部（滚没滚、内容多高都不知道）
    —— 所以"自适应"只能做成"在里面按逻辑视口渲染好、在外面整体缩放"。
40. ⭐ **生产数据会违反文档自称的口径**：口径写"一个学生最多一个未终态课堂"，但**种子/演示脚本直写库、
    以及早期只按同一课时过滤的窄校验**都能造出例外。**判断口径时别只看文档与守卫，要查真实库**。
    守卫夹具本身也会造这种状态（p118 夹具就是"一个学生挂好几场 ACTIVE"）。
41. **SQLite 默认不启 `foreign_keys`**：脚本清理数据不先 `PRAGMA foreign_keys=ON`，级联不生效 → 删出孤儿。
42. **后加的列在建表语句里看不到**（`works.class_session_id` 就是 `ALTER TABLE` 加的）——
    要写清理脚本时以真实库的 `PRAGMA table_info` 为准，别照 `schema.js` 的 CREATE 抄。
43. **p70 会过滤带 `:` 的参数路由**（`!value.includes(':')`）——新加的参数化页面**不在它的覆盖里**，
    别以为"p70 全绿 = 新页面没问题"。
44. **`git checkout --` 一把梭会连别人未提交的改动一起丢**：客户端仓那两个文件里就混着上一轮的活。
45. **本机出网受限**：`curl https://iicili.cyou` 不通（要 ssh 到服务器上跑），浏览器导航也会偶发 10s 超时
    （实际已经打开了、只是回执没回来）。验证"删掉某块 UI"最硬的证据是**在服务器上 grep 已发布产物**。
46. **多行中文提交信息要用 `git commit -F 文件`**（塞进 shell 会被引号/反引号炸掉 —— 我这轮写崩过一次模板字符串）；
    `.tmp/` 在 gitignore 里，放这类临时文件很安全。
47. **守卫可能因缺夹具直接 ENOENT**（p111 要 `.tmp/test-sample.pdf`），那不是你改坏了；
    另外 `set -e` 会把"我就是想看看退出码"的脚本提前掐死（别在同一个 ssh 里又 set -e 又 `echo EXIT=$?`）。

## 八、给客户端项目的说明在哪

用户手上有一份**可直接转达**的对接说明（发送次数显示 + "这是哪节课" + 防御性的 `?sessionId=` +
契约文档要补的三行 + 怎么验收）。要点重述一遍，免得新会话重复踩：

- **不需要做"选课界面"**（正常只有 0/1 节可进）；要做的是**显示**"这节课是哪个课包哪一节"与**发送次数 `used/limit`**；
- 次数上限由**平台**计与拦（客户端**不自己计数**），超限 429 的 `error.message` 原样显示；
- 计数是**按课堂**的（同一个学生换一节就是另一份计数）；
- 换课后要用**新响应里**的 `gateway.key` 并重读 `sends`；
- `classrooms > 1` 只作**防御**（历史/异常库），真遇到才让用户选一次。
