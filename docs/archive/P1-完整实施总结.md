## 🎯 项目目标

实现完整的积分充值与配额管理功能，支持线下付款模式：
- 平台管理员为机构充值积分
- 机构管理员为学生/教师分配配额
- 完整的流水查询和历史追溯
- 课程包价格展示（标价不可购买）

## 📦 交付成果

### 1. 数据库层（1 个表）

#### user_credit_adjustments 表
```sql
CREATE TABLE user_credit_adjustments (
  id TEXT PRIMARY KEY,
  org_id TEXT NOT NULL,
  user_id TEXT NOT NULL,
  credits_before INTEGER NOT NULL,
  credits_after INTEGER NOT NULL,
  credits_change INTEGER NOT NULL,
  reason TEXT,
  adjustment_type TEXT NOT NULL,  -- ALLOCATION / ADJUSTMENT / RECLAIM
  actor_id TEXT NOT NULL,
  created_at TEXT NOT NULL,
  FOREIGN KEY (org_id) REFERENCES organizations(id) ON DELETE CASCADE,
  FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
  FOREIGN KEY (actor_id) REFERENCES users(id)
);
```

**用途**: 记录所有用户配额调整历史

---

### 2. 后端接口（9 个）

#### 平台管理员接口（3 个）
1. **POST** `/api/admin/orgs/:id/credit-adjustments` - 机构充值（增强）
   - 支持记录付款金额、方式、订单号
   - 自动生成详细充值原因

2. **GET** `/api/admin/orgs/:id/billing/account` - 查看机构账户
   - 返回余额、累计充值、累计消耗、付款总额

3. **GET** `/api/admin/orgs/:id/billing/recharge-history` - 充值历史
   - 分页查询充值记录
   - 显示时间、积分、原因、操作人

#### 机构管理员接口（5 个）
4. **GET** `/api/org/members/credits` - 成员配额列表
   - 按角色查询（学生/教师）
   - 显示总配额、已使用、剩余、使用率

5. **POST** `/api/org/members/:id/credits/adjust` - 单个配额调整
   - 支持增加/减少配额
   - 增加时自动扣减机构余额
   - 记录调整历史

6. **POST** `/api/org/members/credits/batch-allocate` - 批量分配
   - 多用户批量分配
   - 一次性扣减机构余额
   - 批量记录调整历史

7. **GET** `/api/org/members/:id/credits/history` - 配额调整历史
   - 查看用户所有配额变更
   - 显示类型、原因、操作人

8. **GET** `/api/org/billing/transactions` - 积分流水查询
   - 按类型筛选（充值/消耗/退款）
   - 按时间范围筛选
   - 返回汇总统计

#### 学生端接口（1 个）
9. **现有接口增强** - 学生端已有配额显示，无需新增接口

## ✨ 技术亮点

### 1. 数据一致性保证
```javascript
// 使用事务保证充值/分配的原子性
const balanceAfter = transaction(() => {
  // 1. 更新机构余额
  q('UPDATE org_billing_accounts SET credit_balance=? ...', [balance]);
  
  // 2. 记录充值流水
  q('INSERT INTO credit_entries(...) VALUES (...)', [...]);
  
  return balance;
});
```

### 2. 双向流水记录
- **机构流水**: `credit_entries` 表（充值、消耗、退款）
- **用户调整**: `user_credit_adjustments` 表（分配、调整、回收）
- **完整追溯**: 两表关联，完整审计路径

### 3. 乐观锁防并发
```javascript
// 使用版本号防止并发充值冲突
q('UPDATE org_billing_accounts 
   SET credit_balance=?, updated_version=updated_version+1 
   WHERE org_id=?', [balance, orgId]);
```
