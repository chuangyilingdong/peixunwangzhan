# 快速测试清单

## 准备工作

### 1. 启动开发环境
```bash
# 终端 1：启动后端服务
cd E:/学习平台正常
node apps/server/src/index.js

# 终端 2：启动管理端
cd E:/学习平台正常/apps/admin
pnpm dev

# 终端 3：启动官网
cd E:/学习平台正常/apps/website
pnpm dev

# 终端 4：启动学生端
cd E:/学习平台正常/apps/student
pnpm dev
```

### 2. 访问地址
- 管理端：http://localhost:5175
- 官网：http://localhost:5176
- 学生端：http://localhost:5177
- 后端 API：http://localhost:3001

### 3. 测试账号
- 平台管理员：需要查看数据库中的账号
- 学生账号：需要查看数据库或创建新账号

## 核心功能测试（30分钟）

### ✅ 测试 1：管理端上传封面（5分钟）

**步骤：**
1. [ ] 登录管理端
2. [ ] 进入"平台课包"页面
3. [ ] 点击"上传封面"按钮
4. [ ] 选择一张图片（建议 < 2MB）
5. [ ] 观察上传状态和自动填充
6. [ ] 填写课包标题"测试课程A"
7. [ ] 添加至少 1 个课时
8. [ ] 点击"创建课包"

**验证点：**
- [ ] 上传按钮显示"上传中…"
- [ ] 上传成功后提示"封面上传成功。"
- [ ] 封面地址自动填充为 `/api/public/file-assets/{id}/download`
- [ ] 课包创建成功

**截图位置：** `test-evidence/admin-upload-cover.png`

### ✅ 测试 3：公开文件接口测试（2分钟）

**步骤：**
```bash
# 1. 获取课程包信息（替换 {series_id}）
curl http://localhost:3001/api/public/marketplace/{series_id}

# 2. 提取返回的 coverAssetId

# 3. 访问封面文件（替换 {cover_asset_id}）
curl http://localhost:3001/api/public/file-assets/{cover_asset_id}/download -I
```

**验证点：**
- [ ] 第一个请求返回课程信息，包含 `coverAssetId` 和 `coverImageUrl`
- [ ] 第二个请求返回 HTTP 200
- [ ] 响应头包含 `Content-Type: image/jpeg` 或 `image/png`
- [ ] 无需 Authorization 头即可访问

### ✅ 测试 5：AI 生成框体数量限制（10分钟）

**准备工作：**
1. [ ] 在管理端编辑课时
2. [ ] 设置 `classroomConfig`:
```json
{
  "generationSlots": {
    "image": { "count": 2 },
    "video": { "count": 1 }
  }
}
```

**测试步骤：**
1. [ ] 学生进入课堂画布
2. [ ] 打开"AI 生成"工具栏
3. [ ] 选择"画面素材（IMAGE）"
4. [ ] 观察底部进度提示
5. [ ] 填写提示词"一只小猫"
6. [ ] 生成第 1 个图片
7. [ ] 生成第 2 个图片
8. [ ] 尝试生成第 3 个图片

**验证点：**
- [ ] 初始显示"生图框体：0 / 2"
- [ ] 生成第 1 个后显示"生图框体：1 / 2"
- [ ] 生成第 2 个后显示"生图框体：2 / 2"
- [ ] 第 3 次点击生成立即提示："本课画布最多支持 2 个生图框体，已达上限。"
- [ ] 不发起 AI 生成请求（检查网络请求）
- [ ] 画布中确实有 2 个 image 类型节点

**截图位置：** `test-evidence/student-canvas-limit.png`
