## 4. 核心业务流程梳理

### 4.1 ✅ 完整的积分管理流程

```
线下付款
  ↓
平台管理员充值（管理端 /organizations/:id）
  ├─ 输入充值积分、付款信息
  ├─ 查看充值历史
  └─ 查看账户信息
  ↓
机构积分账户
  ↓
机构管理员分配（机构端 /member-credits）
  ├─ 查看成员配额列表
  ├─ 单个调整配额
  ├─ 批量分配配额
  └─ 查看调整历史
  ↓
机构管理员查询（机构端 /billing-transactions）
  ├─ 查看积分流水
  ├─ 筛选充值/消耗记录
  └─ 导出流水报表（待实现）
  ↓
学生使用
  ├─ 画布创作（AI 生成）
  ├─ 自动扣减配额
  └─ 查看使用记录（待实现）
```

### 4.2 ✅ 完整的课程包流程

```
管理端创建课程包
  ├─ 上传封面 ✨
  ├─ 配置价格（标价）
  ├─ 添加课时
  └─ 发布课程包
  ↓
授权给机构
  ↓
官网展示
  ├─ 课程广场列表
  ├─ 显示价格（线下购买）✨
  └─ 课程详情页
  ↓
学生学习
  ├─ 进入课堂
  ├─ 画布创作
  └─ 提交作品
  ↓
教师点评
```
