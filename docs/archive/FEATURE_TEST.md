## 问题排查

### 封面上传失败
**可能原因：**
- 文件大小超限（检查上传配置）
- 文件类型不支持（仅支持图片）
- 权限不足（需要 SUPER_ADMIN 权限）

**解决方法：**
```bash
# 检查上传目录权限
ls -la uploads/

# 检查日志
tail -f logs/api.log
```

### 封面不显示
**可能原因：**
- `coverAssetId` 为空
- 文件不存在
- PUBLIC_PLATFORM 可见性配置错误

**解决方法：**
```sql
-- 检查文件记录
SELECT * FROM file_assets WHERE id = '{cover_asset_id}';

-- 检查可见性
SELECT visibility FROM file_assets WHERE id = '{cover_asset_id}';
-- 应该为 'PUBLIC_PLATFORM'
```

### 素材插入不生效
**可能原因：**
- `insertAction` 配置错误
- 目标框体不存在
- `targetIndex` 越界

**解决方法：**
- 检查素材配置的 `snapshot.insertAction`
- 确保画布中已有目标类型的框体
- 索引从 0 开始

### 框体限制不生效
**可能原因：**
- `classroomConfig` 未正确保存
- `generationSlots` 格式错误
- 前端未正确读取配置

**解决方法：**
```sql
-- 检查课时配置
SELECT classroom_config FROM course_lessons WHERE id = '{lesson_id}';

-- 应该包含：
-- {"generationSlots":{"image":{"count":3},"video":{"count":1}}}
```

## 附录：API 端点

### 管理端
- `POST /api/admin/file-assets/upload` - 上传封面文件
- `POST /api/admin/course-series` - 创建课程包（支持 coverAssetId）
- `PUT /api/admin/course-series/:id` - 编辑课程包（支持 coverAssetId）

### 公开接口
- `GET /api/public/file-assets/:id` - 获取文件信息
- `GET /api/public/file-assets/:id/download` - 下载文件
- `GET /api/public/marketplace` - 课程广场列表
- `GET /api/public/marketplace/:id` - 课程详情

### 学生端
- `GET /api/student/projects/:id` - 获取项目（包含 classroomConfig）
- `POST /api/ai/generations/async` - AI 生成（会检查框体限制）
