1. 升级 Node.js 到 v22.5.0 或更高版本
2. 或使用 nvm 管理多个 Node.js 版本

## 🎯 核心价值

### 业务价值
1. **课程推广**：精美封面提升课程吸引力
2. **成本控制**：框体限制避免超量消耗积分
3. **教学效率**：素材智能插入减少重复操作

### 技术价值
1. **公开访问**：封面无需登录即可查看，支持官网展示
2. **智能绑定**：素材与框体关联，提升用户体验
3. **前端限制**：生成前检查，不浪费 API 请求和积分

### 用户体验
1. **管理员**：简单上传封面，自动处理访问权限
2. **学生**：点击素材自动填充，清楚了解生成限制
3. **访客**：官网浏览课程时看到精美封面
