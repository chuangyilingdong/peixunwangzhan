# P1 积分系统完善方案

## 📋 业务背景

**当前模式**：
- ❌ 机构**无法在线购买**积分和课程包
- ✅ 课程包价格和积分仅作为**标价展示**
- ✅ 所有付款通过**线下渠道**完成
- ✅ 线下充值后，平台管理员为机构充值积分
- ✅ 机构管理员可以将积分**分配给学生或教师**

**核心流程**：
```
线下付款 → 平台管理员充值 → 机构积分账户 → 分配给学生/教师 → 使用
```

## 1. 当前系统架构分析

### 1.1 数据库表结构

#### org_billing_accounts（机构积分账户）
```sql
CREATE TABLE org_billing_accounts (
  org_id TEXT PRIMARY KEY,                      -- 机构ID
  credit_balance INTEGER NOT NULL DEFAULT 0,    -- 可用积分余额
  frozen_credits INTEGER NOT NULL DEFAULT 0,    -- 冻结积分
  total_credits_in INTEGER NOT NULL DEFAULT 0,  -- 累计充值
  total_credits_spent INTEGER NOT NULL DEFAULT 0, -- 累计消耗
  currency_paid_total_fen INTEGER NOT NULL DEFAULT 0, -- 累计付款金额（分）
  hackathon_reward_credits INTEGER NOT NULL DEFAULT 0, -- 活动奖励积分
  updated_version INTEGER NOT NULL DEFAULT 1    -- 版本号（乐观锁）
);
```

#### credit_entries（积分流水）
```sql
CREATE TABLE credit_entries (
  id TEXT PRIMARY KEY,
  org_id TEXT NOT NULL,                         -- 机构ID
  direction TEXT NOT NULL,                      -- 方向：IN（充值）/ OUT（消耗）
  type TEXT NOT NULL,                           -- 类型：RECHARGE / USAGE / TRANSFER 等
  credits INTEGER NOT NULL,                     -- 积分数量
  balance_after INTEGER NOT NULL,               -- 操作后余额
  modality TEXT,                                -- 消耗模态（IMAGE/VIDEO等）
  user_id TEXT,                                 -- 使用用户ID
  class_session_id TEXT,                        -- 课堂ID
  project_id TEXT,                              -- 项目ID
  status TEXT NOT NULL DEFAULT 'EFFECTIVE',     -- EFFECTIVE / VOIDED
  reversal_of TEXT,                             -- 冲正的原流水ID
  reason TEXT,                                  -- 原因说明
  actor_id TEXT,                                -- 操作人ID
  created_at TEXT NOT NULL
);
```

#### users 表（学生/教师配额）
```sql
-- users 表中的积分字段
ai_credits INTEGER NOT NULL DEFAULT 0,          -- 用户配额
ai_credits_used INTEGER NOT NULL DEFAULT 0,     -- 已使用配额
monthly_credit_allowance INTEGER                -- 月度配额（可选）
```

#### 数据结构增强

**方案 A：使用现有 credit_entries 表**（推荐）
```sql
-- 充值流水示例

  id, org_id, direction, type, credits, balance_after,
  reason, actor_id, created_at
) VALUES (
  'credit_entry_xxx',

  'user_admin',                      -- 操作管理员
  '2026-09-07 20:00:00'
);
```

**方案 B：新增 recharge_records 表**（备选）
```sql
CREATE TABLE recharge_records (
  id TEXT PRIMARY KEY,
  org_id TEXT NOT NULL,
  credits INTEGER NOT NULL,
  amount_fen INTEGER NOT NULL,              -- 付款金额（分）
  payment_method TEXT,                      -- 付款方式
  payment_reference TEXT,                   -- 订单号/凭证号
  receipt_url TEXT,                         -- 凭证文件URL
  reason TEXT,
  status TEXT NOT NULL DEFAULT 'PENDING',   -- PENDING/APPROVED/REJECTED
  approved_by TEXT,
  approved_at TEXT,
  created_by TEXT NOT NULL,
  created_at TEXT NOT NULL,
  FOREIGN KEY (org_id) REFERENCES organizations(id)
);
```

**推荐使用方案 A**：
- 流水统一在 `credit_entries` 表
- 通过 `type` 字段区分充值类型
- 简化数据结构，易于对账

CREATE TABLE user_credit_adjustments (
  id TEXT PRIMARY KEY,
  org_id TEXT NOT NULL,
  user_id TEXT NOT NULL,
  credits_before INTEGER NOT NULL,      -- 调整前配额
