# 代码结构与路由（当前基线）

> 状态：当前有效基线
> 更新日期：2026-09-08

## 一、应用与职责

```text
apps/
├── website/   官网 + 登录后的学生功能（学习入口、作品、积分、课程、统计）
├── admin/      平台管理员端
├── org/        机构管理员 / 教师端
├── server/     后端 API（原生 node:http）
└── student/    已删除，不再恢复；学生功能并入官网
```

学生登录官网后回到 `/`，通过右上角头像菜单进入：进入学习、我的作品、我的积分、我的课程、学习统计。

## 二、后端路由文件（拆分后）

```text
apps/server/src/routes/
├── index.js            入口与分派顺序
├── auth.js             登录/登出/me
├── adminOrg.js         平台管理员域 + 共享 helpers（handleAdmin）
├── adminCredits.js     平台充值/账户/充值历史（handleAdminCreditManagement）
├── orgAdmin.js         机构域（handleOrg：班级/成员/配额/流水/课程/作品）
├── communication.js    公共内容 + 管理/机构/学生通信
├── fileAssets.js       文件资产（public/admin/org/student）
├── billingConfig.js    计费配置
├── ai.js               同步 AI 使用计费
├── aiGeneration.js     AI 生成 + 异步队列 + 结算
├── analytics.js        分析
└── websiteCredits.js   官网学生积分
```

`orgExtra.js` 已删除（未挂载的空壳）。`adminOrg.js` 已按职责拆分出 `orgAdmin.js` 与 `adminCredits.js`。

## 四、前端结构

- `apps/admin/src/main.jsx`：平台控制台全部页面（仍为大文件，后续按页面拆分）
- `apps/org/src/main.jsx` + `pages/`（MemberCredits、BillingTransactions 已抽共享组件）
- `apps/website/src/main.jsx` + `pages/`（MyCredits）
- `packages/shared/src/`：`api.js`（唯一 API client）、`ui.jsx`（Notice/Pagination/Loading/Empty/ErrorState）、`classroom.jsx`（useData + CanvasClassroom）、`creditDialogs.jsx`（配额调整/批量分配弹窗）、`canvasWorkspace.jsx`

## 五、已消除的重复

- `useData`：唯一实现于 `packages/shared/src/classroom.jsx`，admin/org/website 全部复用
- 配额调整 / 批量分配弹窗：`packages/shared/src/creditDialogs.jsx`，admin 与 org 共用
- 官网公开请求：统一走 `createApiClient`（`packages/shared/src/api.js`），不再散落 fetch
- `Notice` 统一使用 `tone` 属性（info/success/warning/danger）

- [ ] `student.js` 路由保留（官网学生功能依赖 `/api/student`），与已删除的 `apps/student` 前端无关
