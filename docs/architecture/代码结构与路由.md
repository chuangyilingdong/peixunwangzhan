# 代码结构与路由（当前基线）

> 版本：2026-09-13（班级退场 / 课堂模型整轮发布之后）
> 这份文件只回答两件事：**代码放哪儿**、**接口有哪些**。产品口径看 `docs/README.md` 与
> `docs/项目重梳理-03-平台侧重做梳理.md`。

## 一、仓库形状

```text
apps/
  server/     后端（Node ESM，无框架，自己分发路由）
  admin/      平台管理端（React + Vite）
  org/        机构端 / 教师端（React + Vite）
  website/    官网 **与学生端**（同一个 app：官网页面 + /learn 学习环境）
packages/
  database/   建表 DDL + 启动迁移 + 种子
  shared/     三端共用的组件与样式（ui.jsx、classroom.jsx、canvasWorkspace.jsx…）
  canvas/     画布编辑器（React Flow）
deploy/
  production/ 生产部署脚本、运行手册、演示数据脚本
scripts/      守卫（p*.mjs，见下文「怎么自证」）
docs/         见 docs/README.md
```

⚠️ **没有 `apps/student`**：学生端就是 `apps/website`，路由在根路径下（`/learn`、`/my-courses`…）。
生产入口 `https://iicili.cyou/student/` 由 nginx 指到这个 app。

## 二、后端

### 入口与分发

`apps/server/src/index.js` 是唯一 HTTP 入口：按 pathname 前缀把请求交给各 route handler，
handler 返回 `null` 表示「不是我管的」。要加接口，改对应 handler 里的 `part === '…'` 分支。

```text
/api/auth/*        → routes/auth.js
/api/student/*     → routes/student.js
/api/org/*         → routes/orgAdmin.js
/api/ai/*          → routes/ai.js（对话）、routes/aiGeneration.js（生成/任务/素材）
/api/student/vibecoding/* → routes/vibecoding.js
/api/admin/*       → routes/adminOrg.js → routes/admin/*.js（按业务域拆）
/api/public/* + 站内信/帮助 → routes/communication/
文件上传下载       → routes/fileAssets.js
计费/模态开关      → routes/billingConfig.js
```

### `routes/` 各文件职责

| 文件 | 管什么 |
|---|---|
| `adminOrg.js` | 平台端入口：平台权限校验 + 把 `/api/admin/*` 分发给 `admin/*.js` |
| `admin/helpers.js` | 平台端公共工具（含**教师数据范围**的两个 scope 助手 —— 安全相关，改动前先看 p69） |
| `admin/{courses,organizations,users,works,admins,overview,audit,self}.js` | 平台端各业务域（课包 / 机构 / 用户 / 作品 / 管理员 / 总览 / 审计 / 本人） |
| `orgAdmin.js` | 机构端（含**课堂** `/sessions*`、学员许可、课包概览、算力用量） |
| `student.js` | 学生端（课程列表、项目、作品、快照、账号） |
| `aiGeneration.js` | 生成任务（同步/异步）、素材、`/api/ai/center` 学生 AI 中心 |
| `ai.js` | 文本对话（含 SSE 流式） |
| `vibecoding.js` | VibeCoding 会话、消息、产物、提交 |
| `fileAssets.js` | 文件上传/下载/授权 |
| `communication/` | 站内信、帮助与反馈、公开接口（作品广场、CMS 内容、法律文本） |

### `services/` 里几个**承重**的

| 文件 | 为什么重要 |
|---|---|
| `studentContext.js` | **学生进课的唯一门禁**（许可 → 课堂名单 → 课堂进行中 → 入口类型）+ 学生端全部课时状态 |
| `classroomSessions.js` | 课堂领域逻辑：四态、学员六态、完课判定、可加/不可加候选、结算 |
| `computePool.js` | 算力池（学生 × 课包，四种模态共用一个上限）——**额度的权威闸门** |
| `computeGateway.js` | 算力网关令牌（可选线路；网关令牌只是宽松兜底） |
| `modelCapabilities.js` | 模型能力目录 + 请求体模板渲染（生成参数按能力走） |
| `vibecodingArtifacts.js` / `vibecodingIllustrations.js` | VibeCoding 产物与文档插画 |

### 数据

`packages/database/src/schema.js` = 建表 DDL + **启动时迁移**（改表/回填都写在这里，服务启动就执行）。
几条约定：新索引不要写进基础 DDL（老库没有新列会当场 `no such column`），要放在重建迁移之后；
重建表要逐项验（子表会不会被 CASCADE 清空、索引有没有重建）；回填**只按证据**、且必须幂等。

⚠️ **三张班级表是历史表**：`classes` / `class_members` / `class_curriculum_items` —— 保留数据与 DDL，
**不再被任何业务读写**。「教什么、谁来上、谁在名单里」全在 `class_sessions` + `session_students`。

## 三、前端

三端都是「`main.jsx` 里登记路由 + 导航」，页面能抽就抽到 `pages/`，否则内联在 `main.jsx`。

- **平台端 `apps/admin`**：`main.jsx` + `pages/`（12 个）+ `components/`（计费/算力四块面板 + 课包管理）
- **机构端 `apps/org`**：`main.jsx`（内联多数页面）+ `pages/`（`Classrooms` 课堂 / `SeriesOverview` 课包概览 / `StudentGrants` 学员许可）
- **学生端 `apps/website`**：`main.jsx`（官网 + 学习环境）+ `pages/`（我的课程 / 我的作品 / 学习统计 / 作品详情）
- **共用 `packages/shared`**：`ui.jsx`（AppShell/PageHeader/Panel/Status…）、`classroom.jsx`（学生课程中心）、
  `canvasWorkspace.jsx`、`vibecodingWorkspace.jsx`、`console/`（控制台设计系统）

新增页面会自动进渲染守卫的覆盖（它从各 `main.jsx` 的 `<Route path>` 解析路由表）。

## 四、怎么自证（改完必须跑）

```bash
node .tmp/smoke-run.mjs                    # 全量守卫（别用 bash 的 timeout，Windows 上杀不掉子进程）
node scripts/p70-pages-render.mjs          # 三端页面真渲染（能拦白屏）—— 改前端之后必跑
node scripts/p66-student-grant-gate.mjs    # 进课三层门禁（最关键的领域守卫）
node scripts/p69-teacher-data-scope.mjs    # 教师数据范围（安全相关改动必跑）
node scripts/p73-session-migration.mjs     # 课堂表迁移（有数据的库上真跑）
node scripts/p74-session-scope-columns.mjs # 范围字段必须被写入 + 回填只按证据
```

浏览器验收：本地起后端 + 静态服务再走真界面（配方见 `docs/README.md`）。
