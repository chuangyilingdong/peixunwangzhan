# 课堂结束自动提交 · 客户端接入契约（2026-11-03）

> 平台侧已实现：课堂结束后的 **10 分钟宽限期**，允许客户端把刚刚结束那节课的 VibeCoding 作品补交上来；
> 画布作品由平台在老师点结束时自动提交，不需要客户端参与。
> 关联守卫：`scripts/p204-auto-submit.mjs`、`scripts/p205-auto-submit-display-consent.mjs`。

## 一句话

学生忘了点「提交作品」时：

- **画布课堂**：老师点结束，平台用服务器最后一次自动保存的快照自动提交（学生未确认版权）。
- **VibeCoding 课堂**：客户端在 `client-context` 里发现课堂结束，用 **结束前缓存的课堂 id** 调
  `submit-upload`，带 `autoSubmit: true` + `sessionId`；平台在结束后 **10 分钟**内接收。

客户端没开 / 从没上传过 → 平台拿不到本地文件，只能靠老师端的「未提交」提醒。

## 平台接口变化

`POST /api/student/runtime/submit-upload` 的 body 新增两个可选字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `sessionId` | `string` | **自动提交必填**：刚刚结束的那堂课 id（客户端在课堂进行时缓存） |
| `autoSubmit` | `boolean` | `true` = 课后自动补交；允许 `copyrightConfirmed: false` |

规则：

- 只接受 `ENDED` 且 `ended_at` 在 **10 分钟**内的课堂（`RUNTIME_AUTO_SUBMIT_GRACE_MS` 可配，默认 600000ms）。
- 学生必须在这堂课的名单里（`REMOVED` 不算；已完课/未完课都算）。
- 课时必须声明了 `VIBECODING`，否则 `403 AUTO_SUBMIT_WRONG_CLASSROOM`。
- 窗口过了 / 不在名单 → `403 AUTO_SUBMIT_WINDOW_CLOSED`。
- **学生手动交过的作品不会被自动提交覆盖**：返回原记录 + `autoSubmitSkipped: true`。
- 自动交过、内容没变 → 同样 `autoSubmitSkipped: true`，不重复加轮次。
- 自动提交落库：`auto_submitted = 1`，`copyright_confirmed_at = NULL`；
  按 2026-11-03 口径「学生作品不存在版权」，**`auto_submitted=1` 视为已同意展示**，
  平台审核通过后可以直接发布到作品广场（客户端不需要伪造 `copyrightConfirmed`）。

响应新增（节选）：

```json
{
  "id": "vibesub_...",
  "taskId": "3f2c...",
  "autoSubmitted": true,
  "works": [{ "id": "vibesub_...", "taskId": "3f2c...", "autoSubmitted": true }],
  "warnings": []
}
```

自动提交被跳过（已手动交过）：

```json
{ "id": "vibesub_...", "autoSubmitted": false, "autoSubmitSkipped": true }
```

## 客户端要做的

1. **缓存当前课堂 id**：`client-context` 返回 `classroom.id` 时记下来（和 `startedAt` 一起）；课堂消失后还要能拿到。
2. **发现结束**：客户端本来每 5 秒轮询 `client-context`；当 `classroom` 为空（或课堂 id 不再出现），
   且缓存里有刚刚那节课 → 进入自动提交。
3. **选本课任务**：
   - 只看本节课创建/产生过文件的任务（`task.createdAt >= classroom.startedAt`，或 `fileChanges` 里有该时间之后的变动）；
   - 每个任务取最新写入的可提交入口（`.html/.htm/.docx/.xlsx/.pptx`），素材按 `resolveSubmitPlan` 自动打包；
   - 已经有本地提交指纹（`taskId + entryRelativePath`）或平台 `works` 里已有同 `taskId + entryFile` 的任务 → 跳过。
4. **提交**：
   ```json
   POST /api/student/runtime/submit-upload
   {
     "name": "index.html",
     "taskId": "3f2c...",
     "sessionId": "csession_...",
     "autoSubmit": true,
     "copyrightConfirmed": false,
     "files": [{ "name": "index.html", "content": "...", "binary": false }]
   }
   ```
5. **重试/退出**：
   - 网络失败重试 1 次；
   - `403 AUTO_SUBMIT_WINDOW_CLOSED` → 停止，不要继续重试；
   - `200 autoSubmitSkipped` → 已交过，跳过；
   - 全部任务处理完或超过 10 分钟 → 停止。
6. **不要**把课堂开始前就存在的旧任务、或没有可提交入口的任务自动交上来。

## 边界

- **客户端没开 / 提前关闭**：平台没有任何文件，自动提交做不到；老师端结束时会看到「未提交」提醒。
- **多个任务**：每个任务各自成一条作品（服务端按 `(conversation, taskId, entryFile)` 判重），同一任务重交是覆盖。
- **展示授权**：自动提交按「未确认版权」落库；平台把 `auto_submitted=1` 视为已同意展示，
  审核通过后可直接发布到广场。学生手动重新提交会补上展示授权、并清掉「自动提交」标记。
- **迟到**：超过 10 分钟再交会被拒；这是有意的，避免学生往旧课堂里补交。

## 验收

平台侧 `p204` 覆盖：
- 课后宽限期内自动提交 → 成功且 `autoSubmitted=true`；
- 手动交过的同任务自动提交 → 跳过、不覆盖、round 不变；
- 超过宽限期 → 403；
- 非名单学生 → 403；
- 画布结束自动提交 / 空画布 / 已提交无新产出 → 跳过。

客户端联调时按上面的 6 步走即可；平台侧不需要再改。
