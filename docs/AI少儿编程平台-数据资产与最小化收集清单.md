# AI 少儿编程平台｜数据资产与最小化收集清单

> 版本：2026-09-04  
> 适用环境：正式上线准备 / 线上受控内测  
> 原则：只收集有明确产品用途的数据；自动化验收使用临时 SQLite，不读取、复制或写入任何真实业务数据库。本文是工程数据字典与最小化基线，不替代用户协议、隐私政策或法务意见。

## 1. 数据分类与处理边界

| 分类 | 数据资产 | 业务用途 | 来源 | 可访问角色 | 建议保存 / 删除 | 第三方共享 |
|---|---|---|---|---|---|---|
| 账户与身份 | `users.login`、`display_name`、`role`、`org_id`、`status`、有效期 | 登录、角色权限、机构隔离、页面展示 | 用户 / 平台管理员创建 | 本人、所属机构授权角色、平台超管（按权限） | 账户存续期间；注销后按账号删除 / 脱敏策略处理 | 当前不共享 |
| 联系方式 | `users.phone`、`phone_verified_at`、`organizations.contact` | 登录辅助、机构联系；未接短信服务 | 用户 / 机构管理员录入 | 本人、所属机构管理员、平台超管 | 无明确用途不得采集；删除或注销时清理 | 当前不共享 |
| 未成年人及监护信息 | `users.guardian_name`、`guardian_phone`、`guardian_relationship`、`guardian_consented_at`、隐私开关 | 监护关系与同意证据、未成年人保护 | 学生 / 监护人或授权管理员 | 学生本人、必要的机构 / 平台授权角色 | 仅在业务需要时保存；账号删除后按合规保留例外处理 | 当前不共享 |
| 认证与会话安全 | `users.password_hash`、`sessions.token_hash`、会话时间和客户端类型 | 密码验证、会话失效、强制下线、审计 | 系统生成 / 登录过程 | 仅服务端安全逻辑；不向前端返回原值 | 密码重置后旧哈希按策略废弃；会话到期 / 注销后清理 | 当前不共享 |
| 机构与教务 | 机构、班级、成员、课堂、课程授权、开通单 | 组织管理、教学交付、权限隔离 | 平台 / 机构管理员 / 教师 | 按机构、班级、课程权限 | 业务存续期间；归档后限制访问，按删除策略清理 | 当前不共享 |
| 学习过程与作品 | 项目、版本快照、作品、提交、点评、批注、发布申请、举报 | 学习记录、教师反馈、作品治理 | 学生 / 教师 / 机构管理员 | 学生本人、授权教师、所属机构管理员、平台治理角色 | 课程 / 账号存续期间；删除请求按关联资源策略处理 | 当前不共享 |
| AI 输入与生成记录 | `generation_jobs.prompt`、任务状态、模型 / provider 元数据、`media_assets` 预览地址 | 任务状态、额度扣减、结果展示和审计 | 学生 / 系统 | 学生本人、授权教师 / 机构、平台运维授权角色 | 仅为任务与账务所需保存；失败任务按清理策略处理 | 当前 `local-mock` 不调用真实 provider；不得向外宣称真实 AI |
| 文件与资源元数据 | 文件名、MIME、大小、校验和、资源 URL / key、可见性、访问授权 | 文件访问控制和资源治理 | 用户 / 管理员 / 系统 | 所有者及授权角色 | 资源删除后撤销授权并清理孤儿元数据 | 当前未接入真实 OSS，不共享 |
| 计费与积分 | 套餐、充值单、积分流水、用量、价格快照、操作人 ID | 额度计算、对账、冲正、审计 | 平台 / 机构管理员 / 系统 | 所属机构授权角色、平台财务 / 超管 | 账务审计周期内保存；不可变流水不直接覆盖 | 当前未接入真实支付 |
| 运营沟通 | 预约线索 `leads`、通知、站内信、反馈 | 演示预约、通知、问题跟进 | 官网访客 / 管理员 | 平台授权运营角色；机构数据仅限所属机构 | 无跟进价值的线索按清理周期删除；表单必须有同意 | 当前未接入短信 / 邮件 / 微信 |
| 隐私同意与数据请求 | `legal_consents`、`account_requests` | 记录协议阅读、访问 / 导出 / 删除请求 | 学生 / 官网访客 / 管理员 | 本人、必要的治理角色 | 与请求处理和审计需要相匹配；删除请求保留必要审计 | 当前不共享 |
| 安全审计 | `audit_logs`（含请求路径、前后数据、`ip`） | 追责、故障排查、安全审计 | 系统 | 平台安全 / 超管授权角色 | 采用最短可用保留周期；导出和日志展示需脱敏 | 当前不共享 |
| 匿名分析 | `analytics_events.anonymous_id`、事件、路径、白名单 metadata | 第一方转化漏斗与产品分析 | 官网同意后生成 | 仅平台分析授权角色，聚合读取 | 当前策略 90 天自动清理；拒绝同意不采集 | 当前不接入第三方统计 |

## 2. 最小化规则

1. 官网预约只收集机构名称、联系人、联系电话、意向和备注；未同意当前协议版本不得提交。
2. 学生账号只启用教学、额度和安全必需字段；监护字段与隐私开关不得用于广告画像。
3. `password_hash`、`token_hash`、认证 Cookie、密钥和原始凭据不得进入前端响应、普通日志或导出文件。
4. AI prompt、作品快照、批注和文件元数据属于用户生成内容，默认按所属学生 / 机构权限隔离，不用于公开展示；公开作品必须走授权、审核、下架和举报流程。
5. 分析事件只允许白名单事件、去查询参数路径和匿名标识；不得保存 IP、User-Agent、姓名、电话、邮箱或表单原文。
6. 所有查询必须带资源归属条件；客户端传入 ID 不能扩大机构、班级、学生或作品访问范围。
7. 当前未接入真实 AI、OSS、支付、短信、邮件、微信或客户端安装包；任何新增第三方共享前必须补充用途、字段、供应商、授权、保存期限和退出方式。

- 验收脚本：`p8-l01-data-inventory.mjs`
- 验收方式：临时 SQLite 初始化 schema，检查资产表和敏感字段存在于登记表；禁止使用 `packages/data/platform.db`。
- 本清单不能单独将 P8-L02～P8-L06 判为完成；未成年人同意、注销 / 数据请求、内容审核和法务文本仍需分别验收。
