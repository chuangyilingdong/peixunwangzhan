## 一、边界

- 本清单只适用于**不对外公开的内部测试环境**，不等同于正式生产上线。
- 测试网址必须通过 VPN、IP 白名单或 Basic Auth 等方式强制控制访问，不能只依赖“地址不公开”。
- 必须禁止搜索引擎索引，并在页面显示“内部测试环境，不代表正式服务”。
- 测试环境必须使用独立 SQLite 数据库、独立配置和测试账号；禁止触碰 `packages\data\platform.db` 及 `iicili.cyou` 真实线上数据库。
- `local-mock` AI、协议准备稿、未接入的 AI / OSS / 支付 / 微信 / 短信 / 邮件 / 客户端能力必须明确标注，不得宣称真实可用。
- 禁止修改 `packages\canvas`。

## 三、内部 UAT 最小范围

- 平台超管：登录、机构、用户、课程广场、内容 CMS、埋点报表、审计 / 权限。
- 机构管理员：登录、成员、班级、课程、课堂、作品、积分 / 用量、通知。
- 教师：授权班级、课程、课堂、作品点评、发布 / 下架边界。
- 学生：登录、课程筛选 / 详情、项目 / 作品、反馈、账号与协议阅读记录。
- 官网访客：首页、课程、课程广场、作品、预约演示、协议准备稿、统计同意；拒绝同意时不发送统计。
