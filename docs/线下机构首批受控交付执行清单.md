# 线下机构首批受控交付执行清单

- 适用环境：`https://iicili.cyou`
- 交付模式：线下机构、受控账号、人工运维
- 当前能力边界：AI 为 `local-mock`；不包含公开注册、真实支付、短信、邮件、OSS、微信或外部告警
- 记录规则：不记录密码、Token、`.env` 内容；业务数据和账号 ID 仅记录在受控交付记录中

## 0. 交付前信息

- [ ] 机构名称：
- [ ] 机构负责人 / 联系人：
- [ ] 交付批次 / 日期：
- [ ] 参与教师数量：
- [ ] 参与学生数量：
- [ ] 使用课程 / 课时：
- [ ] 负责人确认已获得机构授权，允许创建上述业务数据
- [ ] 已准备账号初始密码的安全传递方式；密码不写入本文件、聊天或 Git

## 1. 平台与机构初始化

- [ ] 平台管理员登录 `/admin/`，确认身份与机构管理权限
- [ ] 创建或确认目标机构
- [ ] 创建机构管理员
- [ ] 机构管理员首次登录 `/org/`，确认机构归属
- [ ] 记录机构 ID、机构管理员账号 ID（不记录密码）

## 2. 账号与授权

- [ ] 机构管理员创建或批量导入教师账号
- [ ] 机构管理员创建或批量导入学生账号
- [ ] 验证批量导入预览、整批提交和重复数据提示
- [ ] 为教师配置可交付课程 / 课时
- [ ] 验证教师可以查看本机构学生名册
- [ ] 验证教师看不到账号创建、批量导入、停用、删除等机构管理区域
- [ ] 用一个非目标机构或无授权账号验证无法越权访问（如有测试条件）

## 3. 教师授课闭环

- [ ] 教师创建班级
- [ ] 教师加入目标学生
- [ ] 教师配置已授权课程 / 课时
- [ ] 教师开始课堂
- [ ] 学生端读取课堂和课程
- [ ] 教师结束课堂
- [ ] 需要保留历史记录时归档班级；不得直接删除有业务关联的数据

## 4. 学生创作与教师反馈

- [ ] 学生创建项目
- [ ] 学生打开魔法画布
- [ ] 学生保存至少一个画布版本
- [ ] 学生确认版权提示并提交作品
- [ ] 教师查看待批作品
- [ ] 教师审核作品并填写点评
- [ ] 学生端可以读取审核结果与教师点评

## 5. 账号生命周期与收口

- [ ] 对需要撤销的临时账号执行停用
- [ ] 需要清除时仅使用软删除；不物理删除历史关联数据
- [ ] 检查没有遗留进行中的课堂
- [ ] 生成或确认交付后的数据库备份
- [ ] 记录异常、处理动作、影响范围和回滚方式

## 6. 交付通过标准

- [ ] 平台、机构管理员、教师、学生核心流程均通过
- [ ] 无跨机构、跨角色、跨学生的数据读取或写入
- [ ] 无生产源码、配置、密码或 Token 泄露
- [ ] 生产服务保持正常，`/api/health` 返回成功
- [ ] 交付负责人确认可进入下一批次

## 7. 交付记录

- 交付结果：`[ ] 通过` / `[ ] 有条件通过` / `[ ] 不通过`

- 临时账号 / 班级清理情况：
- 备份位置：
- 相关 commit / release：
- 复核人：
- 复核时间：
