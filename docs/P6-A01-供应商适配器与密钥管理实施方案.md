# P6-A01 供应商适配器与密钥管理实施方案

> 状态：开始实施（2026-09-05）
> 范围：先建立真实 AI 接入的安全边界和 provider 适配器契约；未配置供应商前，生产继续使用 `local-mock`。

## 当前已知状态

- 生成队列、恢复、重试、超时、取消、积分扣减和审计已经具备。
- `apps/server/src/services/generationProvider.js` 当前只提供 `local-mock`；非 mock provider 会明确返回 `GENERATION_PROVIDER_UNAVAILABLE`。
- 生产环境不得把 API key 写入 Git、前端产物、数据库、日志或聊天。

## 实施顺序

1. 定义 provider adapter 统一契约：名称、模型、能力、超时、请求和响应归一化。
2. 增加服务端密钥来源：systemd EnvironmentFile / Secret 管理器；禁止从请求参数读取密钥。
3. 增加 provider 健康检查和启动配置校验；配置不完整时服务保持可启动但生成明确失败，不回退为假成功。
4. 首个真实 provider 只在用户确认供应商、模型、区域 / endpoint、预算和测试额度后接入。
5. 先在隔离临时 SQLite 和隔离 provider 账号验收，再进入生产灰度；生产默认仍保持 `local-mock`。

## 待用户确认的外部依赖

- 供应商：OpenAI-compatible、阿里云百炼、火山引擎、智谱或其他；只能选择一个作为首个适配器。
- 模型与支持模态：TEXT / IMAGE / MUSIC / VIDEO / PODCAST / DUBBING。
- API endpoint 与区域。
- 单次和每日预算、失败重试上限、数据留存政策。
- 是否允许学生创作内容发送到外部 provider。

## 补充实施记录（2026-09-05）

- 供应商目录新增通用项 `openai-compatible`、`aliyun-bailian`、`volcengine`、`zhipu` 和 `custom`；目录外供应商拒绝保存，custom 必须提供不少于 2 字的显示名。
- 平台端可维护供应商、模型、endpoint、自定义名称、平台单次 / 每日预算和变更原因；机构端可维护本机构单次 / 每日预算。策略强制 `allowStudentExternalContent=false`。
- 任意外部供应商策略下，学生项目生成在进入任务队列前被 `STUDENT_EXTERNAL_AI_BLOCKED` 拦截；拦截不创建 generation job，不产生 usage record，不扣积分。
- 平台保存的非 mock 策略参与运行时 provider 选择；服务端密钥仍只来自 `AI_PROVIDER_API_KEY`，真实 adapter 未实现时明确失败，不回退 mock。
- 隔离验证：契约 8 项、目录 / 隔离 12 项、策略 E2E 18 项通过；P4-O12 / O13 / O15 复跑通过；四端构建通过。测试仅使用临时 SQLite、内置种子账号和假 endpoint。
## 安全验收条件

- 密钥只存在服务器受限环境变量或 Secret 管理器中。
- 日志不得输出 Authorization、API key、完整 prompt 或未脱敏 provider 响应。
- provider 超时、429、5xx、内容安全拒绝均映射到稳定错误码。
- 失败任务不扣积分；成功任务只扣一次；重试不重复产出资产。
- `local-mock` 不得在生产对外文案中被称为真实 AI。
- 未确认供应商和预算前，不切换生产 `AI_PROVIDER`。
- 实施记录（2026-09-05）：
  - 已建立无外部调用的 provider 契约层：`validateProviderConfig()` 校验非 mock provider 的模型、endpoint 和服务端 API key；`normalizeProviderError()` 将超时、429、5xx、安全拒绝和无效响应映射为稳定错误码；`unavailableProvider()` 只返回明确失败，不回退假成功。
  - `apps/server/src/config.js` 新增只读服务端 `AI_PROVIDER_API_KEY` 来源；请求参数仍禁止传入密钥。
  - `aiGeneration.js` 同步/异步失败路径统一归一化 provider 错误码，继续保证失败任务不扣积分。
  - 生产与内测 `.env.example` 增加密钥占位说明；不包含真实密钥，默认仍为 `local-mock`。
  - 补充验证（2026-09-05）：`p4-o12-ai-generation-queue`、`p4-o13-ai-generation-failure`、`p4-o15-ai-generation-cancel` 通过；失败/取消任务 `credits_charged=0`。四端 `pnpm run build` 通过。
