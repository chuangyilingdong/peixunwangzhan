# 招生军师客户端（junshi-desktop）

独立 Electron 内容工作台客户端。登录后加载本地客户端工作台，不再复用或嵌入 `/junshi` 网页 UI，也不依赖 `E:\灵动ai客户端`。

## 当前能力

- 平台机构账号登录，支持二次验证码；
- `safeStorage` 加密保存平台会话和抖音采集 token；
- 登录后打开本地客户端工作台，不加载 `/junshi` 网页 UI；
- 5 个一级入口：首页、做内容、同行采集、我的数据、设置；
- 做内容：一句需求流式生成 3 个版本；也支持今日选题、爆款复刻、热点结合三条灵感工作流；生成后进入完整制作流程：定稿 → 内容方案 → 编导稿与分镜 → 渲染成片 → 发布包 → 人工发布 → 数据复盘；
- 文案大脑：从已转写作品蒸馏写作方法/同行研究简报，带方法与证据，并进入工作流“选写法”阶段；
- 长期记忆：保存机构事实、家长高频问题、表达偏好和禁区，自动进入后续创作上下文；
- 我的数据：同步自己的作品、生成数据建议，并可把建议一键带回“做内容”；
- 客户端专属深色视觉和本地交互；
- 内置独立持久化的抖音浏览器；
- 通过 Chromium DevTools Protocol 旁路读取页面自己发出的主页作品接口；
- 支持当前主页手动采集、自己的作品同步、全部同行同步；采自己的作品前必须先打开“我的主页”并通过抖音登录校验；
- 同行采集采用三步向导：添加主页 → 去采集 → 点“采集当前主页”；
- 单条抖音视频上限 200MB，超限会明确提示；
- 自动生成/兑换 `douyin/assistant` 配对 token，复用现有 ingest 接口；
- 后台隐藏浏览器定时同步，不依赖生产服务器 IP；
- 托盘、关闭到托盘、开机启动、系统通知；
- `electron-updater` 自动检查/下载更新入口；
- Windows NSIS 安装包，可选强制代码签名构建。

## 安全边界

- 不上传抖音 Cookie、密码或浏览器登录态；
- 只上报公开作品元数据（aweme id、文案、播放地址、时长、点赞/评论/转发/收藏）；
- 不绕过抖音登录、验证码或风控；遇到验证时由用户在客户端浏览器内手动完成；
- 平台账号和业务数据仍以 `aicyld.com` 为唯一真相；
- 抖音使用独立 partition：`persist:junshi-douyin`；
- 退出招生军师账号会清除平台会话和采集 token，不会自动退出抖音网页登录。

## 开发

必须使用 Node 22：

```powershell
$env:PATH='C:\Users\Administrator\.vibe-coding\node;'+$env:PATH
pnpm install
pnpm --filter @junshi/desktop dev
```

环境变量：

- `JUNSHI_SITE_URL`：平台地址，默认 `https://aicyld.com`
- `JUNSHI_WORKBENCH_URL`：工作台页面，默认 `${JUNSHI_SITE_URL}/junshi/index.html`
- `JUNSHI_TEST_SESSION_JSON`：仅未打包开发模式可用的会话注入
- `JUNSHI_TEST_OPEN_COLLECTOR=1`：仅未打包开发模式，启动后直接打开本地采集窗口

## 本地状态

位于 Electron `userData`：

- `account-session.bin`：`safeStorage` 加密的平台会话；
- `douyin-assistant.bin`：`safeStorage` 加密的采集 token；
- `desktop-settings.json`：同步间隔、开机启动、通知等非敏感设置；
- `Partitions/junshi-douyin/`：独立抖音浏览器 profile。

## 构建

```powershell
$env:PATH='C:\Users\Administrator\.vibe-coding\node;'+$env:PATH
$env:ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'
$env:ELECTRON_BUILDER_BINARIES_MIRROR='https://npmmirror.com/mirrors/electron-builder-binaries/'
pnpm --filter @junshi/desktop dist:win
```

产物在 `apps/junshi-desktop/release/`：

- `招生军师-Setup-<version>.exe`
- `招生军师-Setup-<version>.exe.blockmap`
- `latest.yml`

### 代码签名

当前仓库没有 Windows 代码签名证书。正式发布时设置 electron-builder 标准变量：

```powershell
$env:CSC_LINK='C:\secure\junshi-code-signing.pfx'
$env:CSC_KEY_PASSWORD='***'
pnpm --filter @junshi/desktop dist:win:signed
Get-AuthenticodeSignature '.\release\招生军师-Setup-<version>.exe'
```

`dist:win:signed` 会启用 `forceCodeSigning`；没有证书时会直接构建失败，避免误发未签名包。没有证书时仍可运行 `dist:win` 生成本地测试包。

### 自动更新发布

`package.json` 的 generic provider 指向：

```text
https://aicyld.com/downloads/junshi-desktop/
```

每次发布需要把下面三个文件上传到该目录：

- 安装包 `.exe`
- 同名 `.exe.blockmap`
- `latest.yml`

客户端会在启动后自动检查，并每 6 小时检查一次；下载完成后提示重启安装。

## 2026-10-26 · 0.3.2 完整制作流程

- 生成文案后不再提示“复制去发布”，改为进入六步制作流程；

- 第 6 步才进入人工发布，发布后回客户端采集自己的作品做数据复盘；
